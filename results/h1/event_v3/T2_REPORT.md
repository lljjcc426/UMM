# T2：输入可观察性与强像素基线

问题：同终态不同过程是否能从实际输入区分？官方视频路径保留了什么？

假设：清楚的累积墨迹可由新增区域和实例模板恢复；最后一帧不能一般性区分实际历史；采样与空间压缩会改变可读性。

方法：五类原创结构（三、十、竖平行、折、交叉斜线）各含正确、换序、反向、半笔、提前换笔、合并事件，共30段24fps无损RGB视频。主采样为8帧，32帧只作像素采样上界；没有使用生成日志作为观察输入。完整逐例预测与采样索引保留在本目录。

对照：B0为真实区域＋RGB墨迹差分；27／14特征均复用同一个旧冻结笔迹线性头，提供相同正确区域；B1／B2使用冻结UMM直接回答，不再训练或搜索提示。

结果：

- 解码像素与保存PNG完全一致。五个正确／换序配对的终帧像素、缓存终帧特征均相同，帧序列在27和14尺度均有非零差异。
- B0在8帧与32帧下，顺序／未知30/30、最终完整状态30/30；8帧全部中间实例状态正确率100%。最终几何覆盖与轨迹比例MAE约0.000189。
- 25段可读过程与5段合并事件分别评价；合并事件的两笔在同一个采样间隔全出现，顺序未知。增加到32帧仍不能分辨同帧内部历史。
- 已有UMM笔迹读出＋正确区域，27尺度顺序／未知28/30，14尺度15/30。两者无新增训练，阈值固定0.5。该读出不是UMM语言原生答案。

失败：27尺度把cross-half、diagonal-half的交叉处误当另一笔出现。14尺度有中横丢失、折笔遗漏、顺序倒置等。旧头原来在27网格训练，14成绩同时包含读出分辨率不匹配，不能据此断言全部信息已丢失。所有失败均保留。

解释：像素链路通过，可继续小头学习；27特征的旧读出已有大部分事件恢复证据。数值非零差异不等于语义识别。静态末帧在同终态对中输入完全相同，不具有唯一恢复顺序的信息。

官方路径细节及本机适配见T2_SOURCE_AUDIT.md。直接调用已完成，细节见下。

下一步决策：保留27原生融合表示，按指定A—D分离实例定位、变化和时间读取。T3验证小训练集可拟合，满足后才预注册T4。本轮没有训练UMM或生成器；D0不能代替未见汉字与风格的验收。

## 官方路径的冻结直接回答

四个固定“三”案例（正确、交换上中、仅上横半笔、上横未完即换笔）各做完整8帧B2和末帧B1，共8次调用。两种条件全部输出[1,2,3]；顺序列表各2/4正确，正确／换序配对同时正确0/1，半笔也虚报另外两笔。提前换笔案例仅列表正确，不能据此认定读懂完成或发现错误。本轮没有调整提示或再训练。

这组仅是四个反例的直接回答诊断，不估计通用视频准确率。B1仍沿用官方span730，单帧时会覆盖到问题文本；主27／14特征比较不经过该语言mask。若后续研究mask修正，必须与原路径单列，当前没有静默修正。

完整路径在本机执行：原采样函数经PyAV接口适配，原逐帧VAE和融合、14压缩、frame-major排列及官方mask/topk1保留；内存适配与最大生成长度见T2_direct_path.json。提取105张去重图，226.7秒，UMM更新0。按采样与头的差异分报，不把缓存的固定每帧噪声复用冒充原脚本CUDA随机数复现。

T2结论：输入可观察性通过，冻结语言输出失败；27融合特征已有可读事件。进入T3小集拟合；没有达到完整H1门槛，也没有生成或统一训练收益证据。
