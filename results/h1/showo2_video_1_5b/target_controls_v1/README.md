# 目标选择与完成比较的控制

使用首轮视觉适配后的完整Show-o2 UMM，权重、解码与图像预处理固定。仅分析原开发集的三个多线条几何组：平行横线、平行竖线和交叉，共12个状态案例。每个条件48题，其中存在24题、完成24题。原图条件复用上一轮相同输入的预测；其他三个条件新增144次调用。

| 输入条件 | 存在正确 | 完成正确 | 存在两问均对 | 完成两问均对 |
|---|---:|---:|---:|---:|
| 原图、原提示 | 19/24 | 13/24 | 9/12 | 6/12 |
| 原图、加入蓝框解释 | 20/24 | 14/24 | 8/12 | 6/12 |
| 加蓝框、相同蓝框解释 | 14/24 | 13/24 | 3/12 | 6/12 |
| 只保留已知目标、原提示 | 24/24 | 19/24 | 12/12 | 9/12 |

蓝框与提示对照相比，存在判断下降6/24，完成下降1/24。框内仍可能有交叉笔迹，框线也改变了输入外观；此前训练没有这种标记。因此该结果只说明当前模型不能直接可靠利用这一种标记，不能推广为所有位置提示都无效。

正确目标被单独保留后，存在从19/24提高到24/24，目标缺失从1/6提高到6/6，完成从13/24提高到19/24。按三个几何组重采样，存在、完成改善的95%区间分别为[12.5,25.0]、[12.5,37.5]个百分点。分组很少，部分区间退化，不能解释为总体稳定。完成仍有5次错误，包括未出现答完整、部分答完整、完整答部分。

实例隔离依赖生成数据的正确标注，属于外部帮助；这24/24不计入自主目标定位门槛。其用途是确认减轻目标选择负担后是否仍存在状态比较错误。数据和干预规则见[控制数据](../../../../data/h1/state_target_controls_v1/README.md)，完整成对比较保存在本目录三个比较JSON中。

## 同图不同目标监督：已完成，尚未稳定改善

加入[同图不同目标监督](../../../../data/h1/state_target_contrast_v1/README.md)：同一图像依次询问各条线，使目标不同但画面相同的题目具有不同答案；同时在相同目标下改变实际进度。该结构提供学习目标对应的条件，实际是否学会由预测检验。

48幅新画面、6个几何组、108个图像与目标组合，产生864条新视觉题；加624条原视觉题和512条原文字题，共2000条。使用完整UMM，从首轮视觉LoRA继续，只更新最后8层q/v的311,296个参数。固定1轮、500步，学习率2e-4，随机种子731，只评价最终权重。图像编码756.7秒，梯度训练1131.2秒，合计约31.5分钟，不含模型载入；全部在M5／16GB完成。训练平均答案损失0.0700，末步损失0.00975。配置、全部训练输入和逐步损失在相邻的`target_contrast_v1_training/`；权重本地保留于`checkpoints/h1_target_contrast_lora_v1/adapter.pt`。

主要评价使用未加框、未隔离目标的完整画面，以及相同固定答案解码。训练没有加入上述开发控制或视觉测试。

| 原参考＋当前开发集，26案例／7组 | 首轮视觉适配 | 追加监督 |
|---|---:|---:|
| 存在正确 | 47/52 | 47/52 |
| 完成正确 | 35/52 | 36/52 |
| 存在两问均对 | 23/26 | 23/26 |
| 完成两问均对 | 17/26 | 17/26 |
| 存在与完成同时正确 | 35/52 | 35/52 |

完成逐题改善的7组配对bootstrap 95%区间为[-4.5,7.1]个百分点，未支持稳定改善。完成中的未出现4→7/12，但完整7→5/14，部分仍24/26。唯一的同当前不同参考配对，原先两种问法均通过，追加监督后只有一种问法通过。不能只报告多答对1题而忽略退化。

仅当前条件去重后100题／25状态，存在仍45/50、完成仍44/50；存在两问均对22→21/25，完成仍22/25。需要未知时仍38/38正确。文字开发回归去重后192题／13组，存在96/96、完成95/96，两问均对48/48、47/48，均保持。原文字测试成绩属于此前权重，不能直接赋给本次权重。

以上配对比较均在相邻的`target_contrast_v1_training/`，原始预测在`target_contrast_v1_reference_dev/`、`target_contrast_v1_current_dev/`、`target_contrast_v1_text_dev/`。

## 同一画面切换目标，能否分别答对

在原12幅多线条开发画面上询问每一个目标，共28个图像与目标组合、112题。首轮模型复用完全相同输入的48条原预测，仅新增64次调用；追加监督后模型完整运行112题。原始基线汇总在`all_target_baseline/`，新模型在相邻的`target_contrast_v1_all_targets_dev/`。

| 指标 | 首轮视觉适配 | 追加监督 |
|---|---:|---:|
| 存在正确 | 51/56 | 51/56 |
| 完成正确 | 27/56 | 30/56 |
| 存在两问均对 | 25/28 | 25/28 |
| 完成两问均对 | 13/28 | 13/28 |
| 同图、真值不同的目标对：存在都答对 | 1/8 | 1/8 |
| 同图、真值不同的目标对：完成都答对 | 0/20 | 0/20 |

最后两项按“图像＋任务＋问法”组合枚举真值不同的目标对，包含两种问法。8和20均为配对次数，仍只有3个几何组；完成0/20表明该组实际预测未能同时区分两目标的不同完成状态。逐题完成增加3题，但两问稳定性和不同目标配对均未改善，不能据此认为目标对应已学会。

评价图像沿用旧开发集，其中原问题以外的目标在各自几何组内状态固定；即使答对，也不能仅凭这项小评价排除目标名称先验或证明视觉泛化。按图像选最有利的答案、忽略目标名称的理论上限为存在50/56、完成42/56，这是标签结构上限，不是实测模型。完整比较在`all_target_comparison.json`及`different_target_pairs.json`。

## 结论与下一步

外部隔离正确实例提高了旧模型表现，完成比较仍有错误；追加监督改善了部分已见训练题，但未带来可靠的开发集目标区分。现有结果支持继续分离目标选择、完成比较和拟合不足，不能确定某一种内部原因。该干预同时增加训练量，没有等预算原数据复习对照，也不能分解监督结构与继续优化各自的作用。

下一步先做少量已见多线条案例的拟合诊断，保持样本、更新次数与评价相同，比较现有最后8层适配与更早层也参与适配。目的在于检验训练配置是否能学会这组基本区别；它不代替独立测试。此对照尚未实施。原130例视觉测试保留，两个前置门槛稳定后再进入顺序学习；H2/H3未开始。

本轮新增两个数据构建／控制分析脚本、两组数据、训练和评价记录。`h1_run_showo.py`及`h1_state_gate.py`增加`train`集合选项；测试覆盖干预标签、同图异标签和预测复用条件；协议、根README、研究进度、实验计划、结论依据及总结果同步更新。没有删除文件。
