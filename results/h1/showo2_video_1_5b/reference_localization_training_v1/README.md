同一28目标上，真实图相对空白图的误差减少16.46像素，12组配对区间[7.58,27.21]；相对训练前减少73.21像素，区间[57.41,92.17]。这些变化没有转化为命中。真实图条件仍比按目标名称返回训练中位数的基线差20.65像素，差值区间[14.66,28.12]。

中位数基线是在本轮评价完成前补充的离线分析：只用训练坐标，按目标名称分别取四个坐标的中位数并取整，拟合时不读开发标签。空白图控制改变了输入分布，其目的在于检查画面带来的变化。完整算式与配对区间见[比较记录](localization_comparisons.json)，不增加模型调用。

输出边界不再颠倒，不等于空间形状合理。训练中有12/84、开发有1/28预测退化为单点。开发8个目标回答相同的`[131,141,298,141]`；空白图24/28回答`[131,131,298,131]`。例如同一三横参考的上横和中横分别被定位到y=101与y=49，顺序与实际位置相反。原始答案和全部坐标误差保留在三个定位目录。

## 结论与下一步

在本轮数据量、冻结视觉编码和最后8层q/v适配范围下，四坐标生成没有可靠学会。训练内就有大幅误差，因此不能仅归因于开发几何变化；真实图优于空白图也不足以说明成功利用了精确位置。这一结果不能证明所有UMM或其他空间输出方式无效。

下一步先检查冻结的UMM视觉表示是否保留可读取的线条位置：用轻量读出头预测空间网格中的笔迹，按几何组划分，并与只用位置先验的对照比较。该诊断现已完成，结果见[空间读出](../spatial_probe_v1/README.md)与[目标条件空间头](../target_grid_fit_v1/README.md)；它们用于区分视觉信息与后续输出环节的问题，不代替UMM本体的状态理解评价。根据结果再决定调整空间输出方式或视觉连接层。没有继续沿相同配置追加训练，也没有运行预测框下的状态推理；当前坐标尚不可用。
