# 位置提示扰动能否改善状态判断

2026-10-17完成。**扰动训练在预测框条件下完成47/56，同预算准确框复习为45/56；其余条件未显示稳定收益，且准确框与无参考存在判断有退化。新权重不替代原基线。** 两组均从原加框状态适配器开始，使用同一256题、1轮／64次更新；一组保留准确框，另一组加入固定±6像素的位置／尺寸扰动。保留相同文字与仅当前复习。扰动由参考几何与目标名称确定，同一目标的不同当前状态使用相同变化。

沿用最后8层q/v LoRA，rank 8、alpha 16、311,296个可训练参数，学习率0.0001、累积4、种子731，答案及EOS交叉熵。除参考＋当前图的框外，初始化、训练样本、标签、顺序和更新预算均保持。只评价最终权重；不追加预算或筛选中间权重。

每组固定评价正确框、上一轮预测框、x方向正6像素平移、垂线方向各侧扩张6像素、原仅当前开发和原文字开发。两种扰动在读取冻结模型扰动评分前固定；评分后发现向下6像素下降最大，于训练前追加该项压力检验，单独标为探索性补充。三项不能代表八种变化均已检验。主要看预测框下完成与目标配对，并报告文字、无参考未知及准确框条件的退化。

预测框是上一轮定位器及原适配器产生的固定图片，两组共享；本轮只更新状态适配器。新权重与旧定位头的兼容性尚未检验，因此本轮不作为同一新权重同时定位和判断状态的验收。

这是单种子、小预算、已有开发几何的探索。两组64步训练与各七项最终评价全部完成。H1的未见字符、字体及真实顺序要求仍保留。

## 当前判断与下一步

框扰动确实能影响答案；本次64步监督只带来条件相关的改善，尚未解决稳定性。当前存在多项退化，保留原适配器为基线，新权重仅作为实验候选，不进入顺序学习。

后续已开展[直接区域状态读出](../region_state_v1/README.md)：用新增状态头比较参考与当前的UMM空间特征，加入新几何与无参考控制，正确／预测区域分别报告。区域信息可被利用，接近完成仍有明显错误。该对照还改变了输入表示和训练参数，不能把差异全部归于移除蓝框；确定性像素比较也不计为UMM独立理解成绩。

新状态适配器与旧定位头的兼容性仍需另测，本轮没有把两个新组件拼接后宣称端到端通过。原130例视觉测试及顺序学习继续保留。

## 实际成本

准确框组图像编码139.7秒、梯度训练144.7秒；扰动组分别137.8秒、161.4秒。两组均256题、64步，更新311,296个参数。冻结模型的前置扰动诊断另用约17.6分钟。

14项最终评价完成，共1744个回答。准确框组记录内用时合计833.8秒，扰动组323.0秒，均不含各次模型加载；后者复用166张图的冻结视觉特征，因此不把耗时差异解释为模型推理提速。缓存记录见[evaluation_cache.json](evaluation_cache.json)，每次推理的`run.json`保存缓存起止数量，语言推理均重新执行。

## 复现

```bash
python scripts/h1_cue_robustness_pilot.py build
python scripts/h1_cue_robustness_pilot.py train --arm exact
python scripts/h1_cue_robustness_pilot.py train --arm jitter
PYTORCH_ENABLE_MPS_FALLBACK=1 python scripts/h1_cue_robustness_pilot.py evaluate-all
```

先构建[扰动诊断数据](../cue_perturbation_v1/README.md)。另一次实验需对各阶段一致指定新的`--data`、`--output`和`--cache`仓库内路径。`evaluate-all`评价两组并保存比较；同一进程内复用未变化的冻结视觉特征，语言模型对每个问题重新计算。两组只更新语言q/v适配器，图像与基座视觉权重相同；缓存不跨训练／测试。准确框组先承担图像编码成本，扰动组复用，因此评价耗时不用于公平模型成本比较。常规推理入口的默认行为保持，新增缓存参数只用于此类受控比较。

模型和训练日志保存在本地缓存，实际输入、损失、原始预测及评分保留在实验目录。新增脚本与派生数据，并为公共推理函数添加可选的冻结图像缓存以减少重复编码；不覆盖旧权重或历史评分，没有删除文件。
