# 由UMM问题表示引导的目标网格读出

2026-10-17完成首轮。**目标条件空间头的开发定位7/28，只读全部笔迹的对照为6/28，尚未显示可靠目标定位。** 该头读取冻结UMM的视觉特征和问题内部表示，模型没有直接生成数字坐标。

## 输入与方法

完整Show-o2加原加框状态适配器保持冻结。复用[空间读出实验](../spatial_probe_v1/README.md)的729个融合视觉token；把同一参考图与“请只定位上横／中横／下横……”等问题送入UMM语言路径，取提示结束位置的1536维隐藏状态。每个问题只含目标名称，不含正确位置或当前完成状态。

新加空间头将视觉token和问题状态各投影为32维，在每个空间格做点积并加偏置，输出目标笔迹概率。共98,369个可训练参数，UMM及已有适配器参数均不更新。训练仍使用36组／84个目标，开发12组／28个目标；语言问题只覆盖本批固定的7种目标名称。

监督仅标出被询问的参考线条，按27×27网格、每格至少8个黑像素定义前景。视觉通道统计沿用训练图；问题通道统计只从84个训练问题得到。固定AdamW、学习率0.003、400次更新、批量8、种子10420，阈值0.5，评价最终头。配置见[plan.json](plan.json)。

从预测网格取最大的四连通部分，以最外侧格子的中心计算边界；无前景则定位失败。四边界均在12像素内计命中。空间网格、连通部分和坐标换算由代码提供，因此此方法属于新增空间头与后处理，不能当作原语言模块已学会坐标生成。

## 结果

| 条件 | 训练命中 | 开发命中 | 开发目标IoU／F1 |
|---|---:|---:|---:|
| 实际目标问题 | 30/84 | 7/28 | 34.6%／48.7% |
| 同图内循环换成另一目标问题 | 4/84 | 2/28 | 21.3%／32.3% |
| 全部笔迹读出，对所有目标相同 | 20/84 | 6/28 | 40.2%／56.2% |

换问题控制保留图像，替换为同图中另一真实目标问题的隐藏状态，仍按原目标评分；不增加UMM调用。全部笔迹对照使用上一实验的预测，采用相同阈值与连通部分换算，不根据目标选择部分。

实际问题相对换问题的开发命中改善17.9个百分点，12组配对区间[0.0,37.0]；相对全部笔迹仅改善3.6个百分点，区间[-11.1,19.2]。目标IoU反而低于全部笔迹对照，不能把7/28解释为稳定目标对应。训练内也仅30/84，损失明显波动，尚不支持把错误完全归因于开发泛化。
