## 运行前固定的设计

使用完整Show-o2-1.5B-w-video-und UMM，M5／16GB，MPS bfloat16；生成模块保留，当前只训练和评价理解路径。从未出现上述退化的原`h1_target_contrast_lora_v1`继续。两组都使用432道同图不同目标参考＋当前题、312道原仅当前题和512道原文字题，共1256题；数据顺序、随机种子和训练配置相同。

|---|---|---|---|

蓝框由完整参考中指定线条的几何确定，不使用当前进度，且不覆盖原黑色笔迹。当前区的蓝框还明确提供了该目标的完整范围，因此属于额外的空间对应信息；其来源是已知参考标注，不能算模型自主定位。仅当前题完全不画框，避免泄露未提供的目标长度。

## 固定评价

每份最终权重评价：432道相应训练题、104道相应参考开发题、112道无框换目标开发题、112道有框换目标开发题、104道原仅当前开发题、208道原文字开发题。原130例视觉测试不运行。

主要结果按以下顺序分析：

1. 在已见训练画面中，是否能让同图不同状态的两个目标均答对；存在和完成分别报告。
2. 开发交叉对照：两份模型分别看相同无框输入、相同有框输入，区分训练提示的作用与测试时提供位置的作用。
3. 原开发的两问稳定性、各状态类别及同当前不同参考配对，不能仅看总体正确率。
4. 文字和仅当前能力保持，沿用问题与RGB像素去重，并与原适配器比较。

每道题使用相同固定答案JSON接口，输出格式由解码器保证。配对沿用既有评分：同一底层笔迹场景、同任务和同问法下，两条真值不同的目标必须都答对。蓝框条件切换目标时，问题与框的位置一起变化；只能据此评价辅助条件下的目标判断。两种问法分别计数，统计按几何组重采样；开发只有3个目标几何组，不把20个完成配对视作20张独立图。

当前匹配训练预算相同，实际耗时分别记录。与上一轮集中训练相比，还改变了训练轮数和数据组成，因此跨轮变化不能只归于复习。当前数据也不能证明未见汉字、字体、时序或生成能力。

## 结果判读

有框训练若在有框开发配对上优于匹配无框训练，可支持“参考位置辅助有助于当前模型的状态判断”；仍需检查无框输入能否迁移、两问稳定性和能力保持。若只有单题均值提高而配对仍低，则继续保留目标混淆的判断。若训练内配对也未改善，应继续检查参考比较与训练表示，不能直接归因于开发几何变化。

若辅助条件有效，后续再研究从参考中预测目标位置，并分别评价定位误差与状态误差。该后续方法尚未运行；两项前置门槛稳定之前，不启动顺序学习、H2或H3。
