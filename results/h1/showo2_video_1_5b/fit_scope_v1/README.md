# 小训练集拟合与适配层范围

本轮已在M5／16GB完成两个适配范围的训练和评价。**最后8层与全部28层都能把48道已见题全部答对；两者的开发完成判断均39/52，同图不同状态的完成配对仍0/20。** 扩大适配范围没有显示出稳定的目标对应收益，当前两项门槛仍未通过。

## 训练与评价安排

从同一份`h1_target_contrast_lora_v1`继续，固定12个已见多线条案例、3个几何组、48道参考＋当前题。两者都保留已有LoRA参数；全部28层条件在此前未适配的早期层加入零输出的LoRA。rank 8、alpha 16、学习率2e-4、种子731、累积4，各训练12轮、144步，不混入其他数据。完整UMM与原生图像路径保留，视觉编码器冻结。

两条件均启用非重入梯度检查点，减少中间激活内存。只评价最终权重，训练前确定的配置与评价范围保存在`plan.json`；未按中途开发成绩选权重。

| 配置 | 最后8层 | 全部28层 |
|---|---:|---:|
| 可训练参数 | 311,296 | 1,089,536 |
| 图像编码 | 36.3秒 | 38.7秒 |
| 梯度训练 | 413.0秒（6.9分钟） | 1105.8秒（18.4分钟） |
| 末轮平均答案损失 | 0.00112 | 0.00024 |
| 首步实际有梯度的适配层 | 8/8 | 28/28 |

全部28层的梯度训练耗时约2.7倍。样本和更新次数相同，参数量与计算成本不同。损失监督答案和结束符，不能直接当作状态正确率。训练记录分别在`last8_training/`、`all28_training/`，权重在本机忽略的`checkpoints/h1_fit_scope_v1_last8/`、`checkpoints/h1_fit_scope_v1_all28/`。

两种配置都可以拟合这组固定目标题，不能再把这组训练内失败直接解释为最后8层没有足够适配能力。该训练集每个几何组只询问原指定目标，成功也可能包含对固定位置的记忆，不能证明任意目标定位。

原开发集有26案例、7个几何组。全部28层相对最后8层的存在正确率差异，配对bootstrap 95%区间为[-3.8,9.1]个百分点；完成为[-5.4,5.4]个百分点。未显示稳定的逐题收益。两配置的“完整”类别均只对5/14；最后8层未出现11/12、部分23/26，全部28层未出现10/12、部分24/26。唯一一组同当前、不同参考的对照，两配置、两种问法均失败。

全部逐题预测在`last8_train/`、`all28_train/`及各自的`reference_dev/`后缀目录。训练前后、适配范围之间的配对统计保存在本目录相应`comparison.json`或`vs_initial.json`文件中。

## 初始损失差异的数值核查

尽管使用相同旧权重和零输出新增层，两个训练运行的首个相同小批次平均答案损失分别为0.12124和0.10468。对此做了事后核查：从同一初始适配器重新载入，固定这4道训练题的图像特征、提示及答案张量，不更新任何参数，分别检查推理、通常训练和输入也保留梯度的训练路径。

| 路径 | 最后8层初始损失 | 全部28层初始损失 | 两配置输出分数的最大绝对差 |
|---|---:|---:|---:|
| 推理，无梯度 | 0.124323 | 0.124323 | 0 |
| 通常训练路径 | 0.121243 | 0.104682 | 1.9375 |
| 两者输入均保留梯度 | 0.104682 | 0.104682 | 0 |

推理时全部分数及4道题的固定答案一致，零输出扩展没有在这组输入上改变初始预测。训练差异在让梯度同样经过早期冻结层后消失，说明它与当前MPS／bfloat16的梯度计算路径有关；本轮未进一步定位底层算子，也未测试其他后端。可复现脚本为`scripts/h1_scope_numerics.py`，完整记录为`initialization_numerics.json`。

因此，本轮记录的是两种实际本机配置的拟合和迁移表现，不能将它作为仅适配层数变化的严格因果证据。若后续再次比较层范围，需要统一梯度路径并重新测量成本。当前两者都能拟合小训练集、目标完成配对都失败的观察仍成立。

## 全部同图不同目标题的训练内检查

最后8层结果出现后，追加检查原`h1_target_contrast_lora_v1`在全部新同图不同目标训练题上的成绩：48幅画面、108个目标案例、432题、6个几何组，只评价参考＋当前条件，不继续训练。时间、原因和范围补充在`plan.json`；该检查属于训练拟合审查，不作独立测试。原始输入与图像均不变，保存于`data/h1/state_target_controls_v1/contrast_training_subset/`。

该追加评价已完成，432题全部保留，没有遗漏。原始预测与评分在`initial_contrast_train/`。

| 训练内指标 | 原同图不同目标适配器 |
|---|---:|
| 存在正确 | 175/216（81.0%） |
| 完成正确 | 138/216（63.9%） |
| 存在两问均对 | 83/108（76.9%） |
| 完成两问均对 | 67/108（62.0%） |
| 同图不同状态目标对：存在都答对 | 6/56（10.7%） |
| 同图不同状态目标对：完成都答对 | 0/84 |

存在中实际缺失35/72、实际已出现140/144；完成中未出现34/72、部分61/72、完整43/72。逐题存在、完成的6组bootstrap 95%区间分别为[77.8%,83.8%]、[61.1%,66.2%]。配对含两种问法，不能把84次配对当作84个独立几何组；0分重采样区间退化为零，也不能用于保证总体成功率恒为零。

原训练数据中，每幅图都选一个最有利答案且不随目标改变的标签结构上限为存在172/216、完成144/216。实际完成138/216仍低于这个上限，同时不同状态目标配对0/84，尚无稳定完成目标区分的证据。存在175/216略超过该上限，说明不能将全部任务概括为完全忽略目标；问题集中在可靠的实例状态对应，尤其是完成程度。

这项结果将下一步收敛为：先在同图不同目标题上检验并改善训练内拟合，再评价开发迁移。保留成本较低的最后8层配置作为起点，固定追加训练预算，保持所有目标都被询问、每个目标覆盖不同状态；同时保留文字状态与缺少参考条件的能力检查。当前没有理由仅凭这次固定目标拟合结果继续扩大层数。后续训练设置将在运行前固定，原视觉测试继续保留。
