# DP-Font 精读：静态笔顺条件与过程执行不是同一件事

来源：[IJCAI 2024 PDF](https://www.ijcai.org/proceedings/2024/0863.pdf)。
本篇内容继承2026-10-13/14核查记录，本轮未重跑实验；关键数值正式引用前应再次查看原表。

## 问题—声明—方法—结论

输入是字符、笔顺和风格条件，输出静态书法图。笔顺编码给出结构先验，PINN损失表达墨水扩散相关约束。作者的主张是改善字形结构与墨迹质量，而不是逐笔视频的规范验证。

Table3历史摘录：

|---|---:|---:|
| 基础 | .699 | 24.91 |

| PINN | .718 | 23.57 |

这些支持该设定下的静态质量变化，不应扩展为“实际书写完全符合规范”。

## 阅读重点

1. 笔顺编码表示的是笔画类别序列，还是包含真实位置、时长和笔尖轨迹？
2. PINN约束的状态、时间和边界条件是什么？
3. 去噪时间、墨水物理时间、实际书写时间分别在哪里出现？
4. 字符/风格训练测试怎样划分，有没有同字同风格泄漏？
5. 与普通骨架或分割先验相比，笔顺序列的必要性是否被独立控制？

## 需要核查而非照抄

历史记录注意到PSNR正文解释与表格箭头方向不一致。这个问题应对照代码/原表，不能自行改数字后当作者结论。

## 能继续研究什么

【假设】笔顺/结构先验可能减少达到固定质量所需的采样计算。
必须给原模型和新模型画完整质量—NFE—时间曲线；比较普通少步训练与先验方法。只出现更好的静态图，不能支持新的过程生成或加速主张。
