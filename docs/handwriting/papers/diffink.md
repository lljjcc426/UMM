# DiffInk 精读：生成友好的潜在空间、少步曲线与实现协议

来源：[论文v3](https://arxiv.org/html/2509.23624v3)；[作者仓库](https://github.com/awei669/DiffInk)。
本页继承此前方法与公开代码核查；不是本轮训练或测速。代码会变化，复现前应固定commit。

## 信息流

文字和参考风格 → InkVAE的轨迹潜在表示 → InkDiT生成整行潜变量 → GMM坐标/笔状态解码 → 可渲染笔迹。

InkVAE用内容识别和书写者风格监督塑造表示。重要区别：潜在重建好，不保证新样本容易生成；历史消融显示类似重建精度下，后续生成内容AR可从74.77%变化到94.38%。

## 公开实现的已记录差异

此前核查的`trainer/dit_trainer.py`中：
- `infer_diffink`用20步DDIM，而非照抄论文五步；
-验证batch配置为1000，不是单条交互测速；
- 预训练DiT中OCR/style可能在`no_grad`里仅作为日志；不能看到loss名称就宣称该阶段同时反传；
- mask、char_points与seq_len参与评测驱动。给定合法风格前缀、已知目标长度和新文本部署需要分别写清楚。不能仅凭使用长度信息就声称未来轨迹泄漏。

## 最先做的实验

固定latent，比较原模型少步、普通一致性学生和MeanFlow类学生；再固定少步方法比较不同latent。逐项检查内容、方向、抬笔、短笔与字符边界，而非一口气更换全部模块。

如果普通蒸馏已解决主要差距，就不应把“事件感知专门机制”说成必要。若少步主要损伤抬笔而非坐标，才有证据考虑离散事件与连续几何的不同目标。
