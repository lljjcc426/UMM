# 汉字笔顺视频：评价协议 v1

2026-10-26。当前是拟定协议；尚无校准通过的通用RGB观察器或模型排行榜。[早期协议](../experiments/benchmark_protocol.md)和[受控PX-01](../experiments/process_probe.md)提供起点，不提供真实自由视频准确率。

## 1. 主评价对象

规范G、模型计划P、实际RGB视频V、独立观察事件E(V)分开存。主分数根据V，不能用P自证执行正确。offline评价可借完整视频和最终字形辅助定位；online理解只能读取决策时已呈现的前缀。规范地区、书体、繁简、合法多序集合在测试前冻结。

先做空间实例一对一匹配，再判断时间。禁止按预测出现顺序给笔画重编号后检验同一个编号序列。IoU≥0.5可作为初始匹配阈值（来源[L001](../reviews/L001.md)的静态恢复协议），但风格形变/配准和阈值须在独立校准集验证；参考风格图、规范轮廓与真实目标实例不混同。

## 2. 主指标与分母

每个样本判为 `confirmed_correct / confirmed_wrong / unobservable / no_output`。已经明确漏笔/错序的样本，即使另有遮挡，也应记已确认错误；无法观察不等于已证错误。无输出保留在全部尝试分母。

设总样本N，已确认正确C、已确认错误W、不可判定U、无输出F，满足N=C+W+U+F。

- **VerifiedOrder-LB = C/N**：全样本可确认严格顺序率下界，主指标。成功需等笔数、所有空间实例完整一一匹配、完整次序属于同一条合法序列、没有已确认的漏/多/拆/合笔。单笔字仍需数量/身份正确。
- **ObservedOrder = C/(C+W)**：可观察样本条件率，分母为0返回null；必须与 **coverage=(C+W)/N**、U/N、F/N同时报告。
- **FullProcess-LB**：顺序之外，同时要求可评估的笔内方向、完整笔画形成、历史保持正确；无笔尖任务用 `ink_only` 名称，接触可见任务另报 `pen_visible`。缺物理证据时不能给真实抬笔/压力满分。
- **Stroke precision/recall/F1**：几何匹配得到TP/FP/FN，漏、多、拆并分别分析。重复同类笔仍须匹配到不同空间实例。
- **Pairwise order recall**：选定一条整体合法序列后，全部要求先后的真实笔对为分母；两笔均匹配且有可确认先后才成功。不可判定/漏笔不计成功，额外笔另由FP和主指标处罚。多合法序不能按每个笔对各挑有利参考拼成虚假的全对序列；单笔字返回N/A。

顺序指标不自动检查方向或真实时间长度。应另外报方向准确/不可观察率、开始结束的时间区间误差、首错定位、状态集合F1、活动笔进度误差。区间跨越采样空洞时保留不确定性，不用一个猜测时间点伪装精度。

## 3. 实际添墨、字形与质量

固定相机配准后，在墨迹层检测非目标提前新增、已完成笔消失/漂移、整笔或整字突现、跨笔重画。**相邻两笔首次出现在同一采样帧只说明该采样下先后不清**；只有更密集原视频显示同步增长，才能标明确多笔同时执行。生成器低FPS、评估器抽帧和codec压缩分别计量。

最终字符/行：OCR字符准确率、CER、整字/整行全对率，结合盲人工核验；清洗规则不得删除任务要求的标点/顺序。中间未完成字不能要求OCR已读出全字。字形用匹配轮廓IoU、骨架/拓扑及必要的LPIPS/风格盲评。像素指标仅在同目标几何和对齐条件下解释，不惩罚所有合法风格差异。

VBench相关子项、VidScribe文字稳定和人工视频偏好用于质量辅表。书写画布本来大面积静止，运动幅度越高不代表越好；要求文字逐步变化时，不能以恒定文字内容稳定作为唯一目标。FVD需同参考分布、固定提取器与样本数，不能单独证明顺序正确或用于单条视频逐笔判断。

效率统一记录完整任务总耗时、首有效笔画时延、GPU/CPU/网络时间、峰值显存、全部模型调用、总NFE、失败重试、有效样本/小时；不把轨迹字/秒等同像素视频FPS。

## 5. 独立观察器与校准

观察器输入V和允许的评价参考，先定位画布/墨迹，再绑定笔画实例，输出可见时间/方向和未知。最初可使用PX-01模板辅助方法；但它未完整检测额外笔、重描、消失及未知风格，必须扩展并验证。闭环UMM的自评不能作为主评测的唯一裁判。

先对同终态换序/逆向、缺笔、多笔、整字闪现、旧笔消失、下采样不可辨等反例检查。再在未用于调参的模型输出/真实录像上做双人独立标注，统计逐类型混淆、错误接受率、未知率、置信区间和争议。人工抽样要覆盖全部模型及失败类型，不能只抽漂亮例子。

P0拟定受控覆盖≥90%、错误接受率95%上界≤5%。上界必须由实际样本数计算；样本太少时即使零错误也不能自动通过。阈值仅用于本项目验收，最终测试上禁止重调。

## 6. 统计与实验公平性

以字符或同终态pair group作聚类单位；重复渲染、同一字多个seed和同一视频帧均非独立样本。按相同提示/seed做配对比较，bootstrap按簇重采样，并分训练种子报告；不能把所有帧数量当有效N。

主要效果预注册：VerifiedOrder-LB差≥5pp且配对95%CI下界>0；字符准确率差的95%CI下界≥−2pp。先用开发集估方差、配对相关和功效，再定正式N；多组次要指标标探索性或采用预定多重比较控制。门槛是研究取舍，无理论成功保证。

文本条件T、前缀P、oracle O分表；输入分辨率/帧数/参考信息、提示改写、教师、总采样与后处理全部披露。等数据曝光和等计算作为两个实验条件分别评。完整样本manifest为评分分母；损坏/拒绝/无输出不得静默跳过。

## 7. 推荐主表

方法｜输入协议｜VerifiedOrder-LB｜ObservedOrder/coverage｜FullProcess-LB｜StrokeF1｜DirAcc/coverage｜FinalCharAcc｜视频质量分项｜端到端成本。

每项都带样本N和适用范围。子表给重复同类笔、交叉、短笔、未见字、未见风格、多字和各错误类型。任何聚合质量分都不能抵消严格过程失败；不存在用美学分加权掩盖错序的默认总分。
