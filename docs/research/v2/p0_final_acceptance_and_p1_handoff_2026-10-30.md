## P1的研究主线

优先回答：未微调UMM在生成完整汉字书写RGB视频时，实际出现哪些可证的笔顺错误；相同输入和seed下，明确规范顺序文本等简单条件能否减少这些错误。后续改进必须对应真实失败证据，不预先认定共享参数、规划、codec或生成执行是瓶颈。高可靠性自动评分器改进保留为可选项。

首批沿用已冻结的**士、小、广、丑4字×2种G0文本条件×2个seed＝16次生成**。它们属于原64请求队列，不另增分母。字集、模型/权重版本、33帧、480×848、12fps、30步、CFG4及seed11/29不变。G1空间权限、空白i2v及理解诊断均在原计划中单列，不混入首批G0比较。8字的参考级别仍为官方规范＋已有整体人审＋AI开发绑定，不升级为完整逐笔金标。

| 首批产物 | 必须保留的证据 |
| --- | --- |
| 每次模型尝试 | request ID、完整输入、seed、原生参数、代码/权重版本、原片、日志、真实显存与耗时 |
| RGB可观察性 | 实际解码帧、PTS及实际采样；缺输出、帧损坏、切镜、整字闪现和无法判断分别记录 |
| 笔顺错误 | 可见笔画身份与先后、首个可证违规时间区间、参考出处；不得从提示或计划推定已执行 |
| 其他失败 | 方向、漏/多笔、历史墨迹消失或改画、初始非空白、字形错误单列，允许多标签 |
| 简单条件对照 | 同字同seed配对比较规范文本与简单提示，报告改善、无变化和退化，不取最好seed |

全部16次初始尝试进入分母；工程失败、未知和错误分别报告。能够看到最终字形但看不清过程时，不自动填笔顺正确或错误。人工主评使用可信规范原件和实际RGB，两位真人独立作答，自动观察只作辅助；本轮没有新增人工任务。

## 从失败证据到改进候选

| 实际观察 | 下一步可检验方向 | 不能提前得出的结论 |
| --- | --- | --- |
| 可辨笔画发生换序 | 相同seed下比较规范顺序文本；必要时另审结构提示 | 仅凭结果不能认定内部规划缺失 |
| 首帧已有整字或过程闪现 | 单列任务合规/不可判定；后续比较全白i2v条件 | 不能把终态正确计为过程成功 |
| 几何身份混淆、漏笔或多笔 | 在G1权限独立表中评估固定空间提示 | 不能把额外几何带来的收益归于G0方法 |
| 短笔、方向或过渡无法判定 | 优先核对原帧、实际采样及codec路径 | 不能把unknown归为已证笔顺错误，也不能先宣布codec是瓶颈 |
| 历史墨迹消失、位移或重绘 | 记录发生区间，再设计有限的历史条件诊断 | 不能仅凭视觉现象认定参数共享有害 |

当前不启动SFT、LoRA、联合训练或新保留集。任何训练方法或新增干预都在真实基线结果之后另行制定与批准。
