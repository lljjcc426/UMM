## 1. 数据分层与许可

| 来源 | 用途 | 严格边界 |
| --- | --- | --- |
| Make Me a Hanzi/AnimCJK等有序矢量 | 规范模板、控制正负例、渲染基线 | 逐字核对地区与规范；几何路径不带真实压力/采样时间；保留来源与衍生许可 |

## 2. 规模与交叉划分

本轮受控候选已构建64观察器开发字＋64独立保留字，加512个主学习字（训练320、验证64、字符OOD测试128）。人审尚缺；完整交叉矩阵的独立字体/书写者/记录格子仍为空，不能将合成渲染变化等同跨来源泛化。主学习字训练侧另按记录/模板/风格实例留出ID测试，不从训练样本的相邻帧生成独立测试。

**应建立交叉测试矩阵，而非只做一个混合OOD集：**

| 字内容 | 风格家族/作者 | 解释 |
| --- | --- | --- |
| 训练见过 | 已见家族但独立记录 | ID性能；不共享原模板或同次采集片段 |
| 微调未见 | 已见风格 | 字内容泛化 |
| 已见字 | 未见家族/作者 | 风格泛化 |
| 微调未见字 | 未见家族/作者 | 双轴泛化 |

另用不同渲染引擎/真实授权录像测试源域迁移。同一原轨迹的颜色、速度、背景及换序正负例属于一个group；同group不跨训练和测试。低频、交叉、重复同类笔、短点、包围和折笔分层，避免把复杂度差异误当纯字符OOD。

“未见”只针对本次微调划分，基础模型预训练暴露未知。G1标准字库覆盖情况必须披露。规范许可、字体许可、模型许可分别核。

## 3. 样本schema与信息隔离

清单至少包含：sample/group/character/instance ID、source_revision、许可、规范及合法序列集合、writer/style/template/renderer身份、split、原生fps、帧时间戳、事件可见区间、接触信息的来源或N/A、媒体hash、标注者及争议。

目录逻辑分为`model_inputs`、`training_targets`、`evaluation_only`。完整终图、真值事件边界和生成器日志不得进入T推理；P只见prefix_end之前的媒体；文件名、字幕、颜色编号和隐藏元数据不能泄漏正确顺序。规范实例ID与实际出现时间分别存，不能按时间给几何重新编号。

正确/换序配对保持最终形状、笔数、速度分布和画面风格，交叠处用合成规则控制终态一致；另设真实压力/晕染场景，不强求真实墨迹全部同终态。错误过程训练理解分支；生成分支的正target仍要求符合该协议。坏前缀无合法在线修复时保留错误标签，不伪造合法后续。

## 4. 评价单位与三态输出

主单位为一次完整生成尝试，输出需从空白开始。观察器从真实RGB提取实例和时间，与独立规范标注做几何匹配，之后检查顺序。生成器自报计划不算实际执行；由硬渲染保证的性质归因执行器。

每次输出分为**可确认正确、可确认错误、不可判断**，另记录无输出/解码失败。令C为确认正确数、U为不可判断数、N为全部尝试数：

`VerifiedOrder-LB = C / N`

`UnknownRate = U / N`

`Coverage = (N - U - invalid_output_count) / N`

同时报可观察有效输出上的条件正确率；无输出计失败并单列，不得使主分母减小。`(C+U)/N`仅是把未知全部视为可能正确的识别区间上端，不是置信区间，且前提是观察器已知判定可信。观察器误差另用人工校准CI报告。

StrictOrder要求等笔数、空间实例一一匹配和允许的完整先后。主RGB协议还报告前笔完成/后笔开始、方向、提前/同步添墨、旧墨迹消失及完整过程成功。只报开始顺序可能放过未完成即换笔，故需独立完成先后项。

当低fps使两笔第一次同帧出现，只能记顺序未知；当更密集可见帧明确显示两笔同时增长，再记执行重叠。沿不透明黑墨完全重描可能无可见证据，RGB任务不宣称识别所有隐蔽物理动作。没有笔尖/传感时接触压力和物理抬笔标N/A，主要评价可见墨迹事件。

## 5. 主表与辅助指标

| 层 | 指标 | 统计口径 |
| --- | --- | --- |
| 主生成效果 | VerifiedOrder-LB、完整可见过程成功率 | T从空白自由滚动、全部尝试分母；P/O另表 |
| 结构与时间诊断 | Stroke precision/recall/F1、实例顺序、方向、首错位置、完成先后 | 先几何身份再时间；笔型准确不能替代实例 |
| 最终内容 | 整字/整行准确率、CER、独立人工字形核对 | OCR版本固定，艺术风格下审核误识别；中间未完成字不按完整字OCR处罚 |
| 外观/风格 | 有参考时几何/LPIPS，盲评风格、可辨性、自然度 | 自由风格生成允许多个正确终图，不强行与唯一参考逐像素对齐 |
| 视频质量 | VBench相关子项、局部闪烁、连续性；配参考集时FVD等 | 通用指标不替代笔顺；动态程度越高不等于书写越好 |
| 过程保真 | 已有结构保持、非目标新墨迹、拆并笔 | 不以全帧平均掩盖面积很小的短笔 |
| 成本 | 全链延迟、训练GPU时、参数、NFE、全部重试、有效样本/小时 | 理解/裁判/渲染和失败尝试均计入 |

L001的IoU≥0.5实例匹配可作校准起点，不能不经验证用作所有字体的普遍阈值。几何匹配若无法可靠建立，自由风格样本需人工身份对应或标unknown，不能按预测顺序强配。形变配准不得消除真实位置错误。

## 6. 评价器必须跨两个域校准

EVAL-01先在独立受控集测试交换、逆向、漏/多笔、整字闪现、旧墨迹消失、降帧歧义；拟定覆盖≥90%、误接受95%上界≤5%，都属于项目门槛。按字/轨迹group统计，不能将同一模板大量帧当独立样本来虚假缩窄区间。

EVAL-02用开发字上的真实模型输出，双人独立盲标并仲裁，分错误类型报告误接受/误拒绝/未知。该域不过关时，主结果采用人工标签和已校准子集，自动分仅作诊断。评分器不得仅在主模型输出上校准，也应覆盖规则、轨迹、通用视频和共享模型候选的错误分布。

阈值只能在校准/验证材料选定；正式保留集用于一次冻结评测。任何重试反馈裁判与最终评判者分开，自动评价和模型同架构时增加独立人审以检查共同盲点。

## 7. 预算、效能和论文主张

正式比较尽可能用至少3个独立训练seed，推理seed另固定；少于此仅作探索且说明预算。按字符/来源group配对bootstrap，必要时分层/多级重采样考虑seed相关；报告点差和CI，不把平均提升直接叫统计显著。

v1的5pp最小意义差和2pp字形非劣界保留为讨论起点；用开发集效能估计后预注册。新增风格非劣容差需盲评校准，不能空缺时宣布全质量无损。预先指定核心对照与主指标；大批消融的多重比较使用修正或标探索性。

从空白T全流程结果是首篇主表，teacher-forced单步、P续写或O特权执行不替代它。若只在G1字库或单渲染器有效，将结论限定到该范围；若只有人工可判，明确自动评分器仍未成熟。严格笔顺、最终内容、风格和成本分别展示，不用未经校准加权总分掩盖取舍。
