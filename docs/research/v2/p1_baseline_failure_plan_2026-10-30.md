## 3. T/P/O及信息权限

T主任务为从空白开始、完整写出指定单字、固定画布、黑色单线、无手笔遮挡的RGB视频。使用统一文字风格描述，不提供目标字终图；本小轮不验证独立图像风格参考或风格迁移。原生t2v若首帧已有字迹，记录初始非空白违规，仍保留原片和分母。

| 条件 | 接口/权限 | 用途及限制 |
| --- | --- | --- |
| T-G0原生简提示 | t2v；字、规范名称、空白/风格要求 | 未微调原生基线 |
| T-G0规范顺序文本 | t2v；额外明确规范笔型序列 | 简单条件工程；不增加几何 |
| T-G0空白图条件 | i2v；仅真实全白图＋相同规范顺序文本 | 固定初始画布的对比；全白图不含目标，属于T，不记作P |
| T-G1模板空间文本 | t2v；顺序文本＋统一固定模板实例bbox/身份对应 | 适合现有接口的弱结构提示；额外几何权限单表，AI绑定仅开发级；不宣称原生硬mask控制 |
| O确定性规范渲染 | 精确几何及规范程序，CPU执行器 | 8份计划对照；精确路径/时序特权单列，不与T-G0等信息排名。先按对应重排，不把源次序当规范，候选渲染也须独立检查 |
| P历史诊断 | 实际可见前缀，隐藏未来及计划 | 以理解为主；原生i2v只能接末帧的续写明确记P-last-frame，不能宣称完整多帧前缀条件已支持 |

G1实例按无序稳定ID提供空间信息，规范绑定单独声明；全部可比较G1方法获得相同模板。模板不是某个生成输出的真实目标几何。强硬mask合成若后续执行，必须归入外部执行器/O能力，本轮不实现模型结构控制或修改权重。

## 4. 固定输入与尝试量

原生设置沿用已测：480×848、33帧、12fps、30步、CFG4、KV cache开启、提示增强关闭、单卡、单输入串行。视频编码时长33/12＝2.75秒，最后采样时刻32/12，二者分别记录。seed固定11、29、47，同时设置原生global/validation seed。

| 运行层 | 计划量 | 计数关系 |
| --- | --- | --- |
| 先导T-G0 | 4字×2文本条件×2 seed＝16次 | 完整64次计划的子集，通过同协议运行后复用，不重复计样本 |
| 完整两种T-G0文本 | 8字×2×3 seed＝48次 | 含上述16次，扩展新增32次 |
| 空白i2v | 8字×1条件×seed11＝8次 | 与对应T-G0详细文本seed11配对 |
| G1空间文本 | 8字×1条件×seed11＝8次 | 单独几何权限表 |
| 确定性渲染O | 8字×1＝8段CPU对照 | 不作为8次随机模型成功 |
| SO-01受控前缀理解 | 4例×5条件＝20次 | 完整前缀、末帧平铺、相关遮蔽、等面积无关遮蔽、同末帧异历史 |
| SO-01真实生成理解 | 4份真实输出×完整前缀/末帧＝8次 | 由固定request ID选择；缺片不挑优替换，记录缺失；共28次理解调用 |

完整建议量为**64次生成＋28次理解＋8段CPU对照**。只跑先导时为16次生成＋4段CPU对照；先停止取得原片、资源和可判性证据，再决定扩展。SO-00 codec重建另有最多8个审计输入，重建不作为新模型生成成功样本。

33帧的短时长只限定本轮受控问题。点的9笔尤其需要SO-00可观察性检查。若原生采样压缩到无法独立看清短事件，先报告表示证据不足；拟改65帧或时长时建立新版本、另批预算并对全部可比方法重跑，不把变更后结果混入33帧主表，不用插帧补造证据。

所有初始请求均进入N；重试必须追加attempt ID、原因、耗时和成本。首轮成功率与含重试总尝试率分别报告，不取最好seed或丢失败。不自动重试内容不正确的有效输出。技术失败最多一次同设置恢复重试的建议预算须随GPU执行批准冻结，原首败保留。每次调用超15分钟先记录超时并停止队列；环境修复、长时长或新方法不得偷偷扩量。

## 5. SO-00：解码、时序采样与codec

保留生成器原输出tensor/帧（若上游可采证）、原始MP4、ffprobe流/逐帧PTS与解码RGB，核对尺寸、33帧、实际fps、PTS单调、持续时间、重复/丢帧和像素格式。先看实际源帧，再看编码片；不能先插帧、稳定、去噪或改序后当原始结果。

对最多8个有可信可见笔画的输入，保存“原始RGB→模型原生抽帧后的实际索引/PTS→VAE encode/decode重建”三份。模型原生抽帧索引必须来自实际数据加载器采证；计划中的均匀抽帧不能冒充实际索引。Decord/ffmpeg实际读取帧与时序发生差异时先定位、保留失败，不将wheel标签警告本身当作已证数据错误。P0已验证路径的非阻塞结论保留。

按短笔、方向锚点、首末帧及相邻笔过渡检查事件是否仍可判，分别记录消失、合并、方向不可见和颜色/形变。VAE重建需GPU，当前未执行；不能凭未来代码设计声称codec已经排除。未采证到原tensor或抽帧索引的路径记证据缺失，不宣称SO-00通过。

## 6. EVAL-02：实际RGB独立人工评价

两位真人独立，审核前隐藏方法、seed、提示计划、自动分数及预设错误标签；先看实际视频和逐帧，再按独立规范原件记录。每项可填correct/incorrect/unknown；not_applicable仅用于确无该分项的任务，不作为成功。保留原始逐人提交、版本、首错时间区间与原因，之后另存一致/分歧，不相互覆盖。

| 分项 | 判定证据 | 典型错误/未知 |
| --- | --- | --- |
| 笔顺 | 实际起墨、笔画身份及先后与规范比较 | 换序、提前增墨；身份不清或同帧并起为unknown |
| 方向 | 同笔内部可见增长方向 | 反向；仅终态或端点不可分辨为unknown |
| 完整性 | 缺笔、多笔、截断、覆盖或不属于目标的墨迹 | 不以完整终态推定过程正确 |
| 历史墨迹 | 实际旧墨迹是否消失、位移、改画 | 擦写、闪现、整字重绘；风格纹理变化单独描述 |
| 时间可判性 | 原帧可否定位形成过程 | 切镜、整字闪现、速度太快、遮挡等记录原因 |
| 最终字形 | 独立末帧的目标字可辨性与基本结构 | 错字、不可辨、严重变形；与过程指标分开 |

初始空白、画布稳定、手笔遮挡/其他字形也单列任务合规项。字形评价允许合法风格变化，不以像素模板IoU作为唯一正确依据。

双人均明确通过某分项才记该项verified correct；两人一致且有可见违反证据记incorrect；冲突或证据不足保留unknown。单个明确违反可以判联合失败，其余分项仍各自保留未知。主指标为全N的联合verified-success下界，另报分项正确/错误/未知、有效RGB比例、工程失败率、最终字形质量及双人一致率。全无输出不能算人工笔顺错误，也不能从分母删除。

自动观察器、OCR/末帧判断、模型自报顺序和计划均为独立辅助列；不参与盲审，不覆盖人工。先冻结自动版本再读真实输出，不以反复修改阈值拟合这批结果；若改版，旧预测保留、开发结果单列。低覆盖、未知或无法匹配G0自由几何均如实报告，不限制人工主评继续进行。

计划人工量：先导16生成＋4对照＝20视频，两人各20次，共40视频审核；完整64生成＋8对照＝72视频，两人各72次，共144次，含先导已有审核。若另做28份理解回答判断，两人共56次，合计200次；此为后续预算，**本轮没有向用户分派这些任务**。分项在一张卡内提交，不拆成多轮机械操作；参考争议另列，不擅自追加第三人。

本轮8字、少量seed是开发诊断，按字和seed配对展示，不用帧或同字多视频制造独立样本量；不宣称总体5%风险界、跨书写者泛化或发表级显著性。

## 7. SO-01：历史诊断与失败分类

4个受控前缀来自先导字及已有可见事件，未来帧、规范执行日志和答案不进入理解输入。末帧平铺与完整前缀使用相同容器帧数，明确其唯一信息差别；遮蔽相关笔迹与同面积无关区域，面积、位置和遮蔽时段保存。同末帧异历史只在实际可构造且末帧一致的受控对上比较，不任意乱序真实帧后称真实书写过程。

真实生成诊断固定取4个request ID的输出，不按成功或错误类型挑选；缺失记录缺失。要求描述实际观察次序、方向、已完成/活动实例、首错和不确定性，不能复述规范答案。相同末帧可对应相同下一合法动作，不要求人为不同答案。只支持末帧的i2v续写保留为可选P-last-frame，首批不额外生成续写视频；完整前缀条件能力待独立接口验证。

失败分类先区分部署/无输出/解码、表示或可观察性不足、任务合规、目标字形、规范身份/方向、次序、漏多笔、历史墨迹以及裁判分歧；允许多标签并保存首个可证错误区间。观察到错误类型只能形成定位线索，不能据此认定唯一机制瓶颈。
