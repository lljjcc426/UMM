## 研究问题和范围

候选假设是正确的 `(I,D)` 配对训练相对普通 Image→D SFT、文本学习及独立支路学习是否提供额外收益，能否迁移到重复笔型的实例身份和相对位置。S0–S1 构建检验所需的数据和评价工具，模型增益尚无结果。

`I` 为 256×256 RGB 黑字白底完整字图，不带笔画编号、高亮、角标或字符文件名。`D` 为规范的有序**五类主笔形**名称与末尾汉字，以顿号连接。类别固定为 `1横类、2竖类、3撇类、4点类、5折类`，包含规范规定的附笔形；例如“捺”并入点类，“提”并入横类。`永` 的该版本描述为 `点、折、折、撇、点、永`。这些名称表示粗类，不能解释成细笔型均为点或折。

本轮只有五类标签。细笔型 ESA、细笔型逐位置准确率保持空值，禁止与五类结果混算。`[EOF]` 不作为字面训练内容；本轮不下载或加载 tokenizer，真实 EOS ID/追加方式留待各模型原生 tokenizer 审计，不能猜测。

不引入部首、部件、语义、拼音、整字结构或视频形成历史监督。完整训练对可供后续双模态方法与普通 SFT 使用，本轮没有训练器、损失或模型更新。新增实例监督属于后续独立协议。

## 数据来源与许可

[来源登记](../../../data/research/paired_strokes_v1/source_licenses.csv)给出逐源职责、许可、实际导入与限制。

- 字形采用本地既有 [Make Me a Hanzi graphics](https://github.com/skishore/makemeahanzi/tree/bddc96d41bef78427ed0e034e9f7e31d71fd1b92)，固定 revision `bddc96d41bef78427ed0e034e9f7e31d71fd1b92`。衍生图像、几何及 masks 保留 Arphic Public License、原版权、修改日期和说明；命名为 UMM Paired Stroke Pilot。未导入 dictionary 的部件等字段。单个字形无法确认来自哪一支 Arphic 字体，记录为 unspecified，不能声称独立字体测试。
- 规范序列独立读取教育部 [GF0023—2020](https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/202103/W020210318300204215237.pdf)的数字编码。使用既有 PDF 与文本缓存，PDF、页面图只供本地查阅，不承诺可公开再分发。序列没有从 SVG 路径类型反推。
- [CCD 原论文](https://aclanthology.org/2025.naacl-long.16/)仅作任务定义参考。论文实际链接 `github.gatech.edu/xwu414/Chinese-SubCharacter-Dataset.git`，公开可用性与数据许可未确认；导入样本数为 0，称 CCD-compatible，不报原论文的复现分数。
- [CCSE 作者仓库](https://github.com/lizhaoliu-Lec/CCSE)提供 COCO 格式实例数据下载入口，主页未给出明确数据许可；本轮未下载。实例掩码本身不提供规范时序和方向资格，Kai 数据与 Arphic 的源关系也需核查。
- [CASIA 官方说明](https://nlpr.ia.ac.cn/databases/handwriting/Online_database.html)描述实际在线轨迹；本轮未追加数据。真实落笔顺序不能自动作为规范顺序，历史 CASIA 记录也不升级为新保留集。

## 规范解析与字形绑定

`parse_norm` 按两列版面读取 Unicode、字表序号、笔数与换行编码；字符必须与 UCS 一致，笔数必须与编码数完全一致。8105 个规范索引中，7832 字解析通过，273 字未取得完整可解析序列。270 个被拒文本块原文保留于私有目录；有的块含多个字，块数与字数分开记录。未通过记录不补猜。

SVG 与规范笔数不一致的 16 字进入 `source_rejections.jsonl`。发布范围限定为规范一级字的可解析、笔数一致子集。**笔数一致只支持候选配对，不证明 SVG 第 k 个实例等于规范第 k 笔。**每个样本的规范页码、序列与独立实例审核资格均分别保存。

## 数量、划分与泄漏

本次 256 字：16 个审核开发字，以及 240 个额外 pilot 候选字。16 字为一、二、三、十、土、士、木、未、末、口、日、田、人、大、中、永，共 54 笔，保留既有开发暴露身份。

240 字按种子 `20261102`、笔数层分配为 192/24/24 个 `train_development / validation_development / test_development`。三组均为开发分区，完整数据已经参与工具开发，不称新的正式保留集；D-MAIN 尚未建立。构建时规范/许可和独立人工核查齐备的 D-SMOKE、D-PILOT 合格数量均为 0；同日审核后D-SMOKE数据侧为16对，D-PILOT仍为0。

额外 240 字排除已知历史 647 字暴露集合，包括 P0 全部 640 个模板、工程目录、Batch A/重启准备目标及本次审核字。验证与开发测试的不同字符，仍只表示本次划分的字符隔离；未来模型是否预训练见过无法保证。正式后训练字符 OOD 必须在实际训练前结合最终训练清单再次锁定。

`char_id / glyph_template_id / source_record_id / group_id` 及相同图像不能跨分区。所有模板扰动继承其 group。没有未见真实字体或新采集源，风格 OOD、双轴 OOD 留空。原图和 mask 在生成时各登记一次哈希，不进行重复全缓存扫描。

`manifest.jsonl` 保存规范、许可、分组及构建时资格。`training_pairs.jsonl` 仅导出 192 个训练候选的 `id / model_inputs.image / training_targets.description`，对应 `data_schema.json`；同日审核后另存相同窄格式的`smoke_pairs_reviewed.jsonl`。训练端只应读取这类导出，不读取完整 manifest、源码子集或 `evaluation_only`。图片名为不含字符的 opaque ID，PNG Notice 只有许可与修改说明。

## 独立逐笔真值

`evaluation_only/geometry.jsonl` 与 256 个压缩 mask 文件包含 2243 个 SVG 笔画实例、归一化有向路径、起终点与关系。其资格统一为 `source_derived_unreviewed`。训练所用规范序列和这份候选几何分别取自规范文本与 SVG；几何本身仍与渲染图同源，不能据此宣称独立来源或独立审核已完成。

独立审核需由实际审核者对照规范原页，逐笔确认实例、次序、方向和适用关系，并记录身份、范围、证据、版本及争议。`review_template.jsonl` 提供16字×E3/E4/E5的48条待填记录，`reviews.jsonl` 构建时为空，同日后续已接收48条实际审核记录。只有实际发生的独立人工审核可提交 accepted；AI预审、程序输出、旧粗筛及单元测试虚构审核者均不算提交。资格与 gold revision、规范引用、全部实例覆盖相绑定，争议阻止相应指标准入。

审核包位于 `private/paired_strokes_v1_2026-11-02/review/index.html`，含每笔轮廓、候选编号、绿色起点、红色终点及独立规范原页。只有16个简单开发字进入首批空间/方向请求；复杂字 masks 已准备，尚无相应正式审核或得分。

**初始构建时独立接受真值为0；同日后续审核现已归档16字/54笔，E4保留“未”的unknown与“一”的不适用。**当前无模型预测，E3/E4/E5模型分值仍保持null。若审核发现实例顺序错位，须修正候选绑定并升版本再审核，禁止通过改预测答案或自动通过修复。

## 固定评价定义

| 项 | 定义与输出 | 完整分母与限制 |
|---|---|---|
| E1 | E2 预测序列长度派生笔数；计数准确率、有效输出MAE | 缺答/格式错/unknown保留；MAE注明仅有效序列 |
| E2 | 五类完整序列 ESA、Levenshtein距离除以两序列最大长度、逐位置准确率 | 多笔位置也扣分；完整错误即整字错误；末尾字符不参与 ESA |
| E3 | 无标记字图，回答规范第k笔内部归一化点 | 独立身份真值准入后评分；点在多个实例交叠区为unknown；这是点身份识别，不报Mask AP |
| E4 | 两笔 above/below/left/right/intersect/longer 布尔判断 | 每种关系及重复笔型分表；候选真值不计分；真值容差带保留ambiguous_gold |
| E5 | 起点到终点位移八方向；可附归一化起终点 | 静态规范先验；弯折的完整笔内转向不由端点位移证明；平均端点误差按画布对角线归一化 |
| E6 | 配对正确性布尔判断 | 正对、同字错序、错类、OCR可解控制及碰撞兼容控制分别报告 |
| E6R | 隐去尾字，在五类编码描述中掩盖一个位置，回答该编码 | 与 E6 匹配准确率单列；不得混计 |
| E8 | 仅字图的单字OCR exact match | 仅输入健康检查，单列health_only，不计主综合结果 |

画布归一化坐标 x 向右、y 向下。E4 左右/上下用实例轮廓质心差，2%画布以内为未知；longer用中线弧长比，差别在5%以内为未知；intersect 指256像素栅格轮廓接触/重叠，不能推断是规范的“相接”或“相交”。E5 八方向以图像坐标中起终点位移角度分箱。所有几何定义在模型结果产生前固定。

1504 条离线请求已准备，全部未执行模型推理：E2 256、E3 54、E4 108、E5 54、E6 776、E6R 256。E1随E2派生。

补齐套件在原1504条之外增加文字先验256条（PRE-02）、oracle实例高亮216条（PRE-06）和OCR健康检查256条（PRE-07），合计2232条。文字先验无图片；oracle高亮不绘起终点。主表、split分表和主终点CI仅用原主清单；对照按permission/condition单列。新增PAIR审核只确认完整字图及规范五类序列，不能替代E3/E4/E5独立逐笔核查；合格pilot窄导出保持原训练/验证/测试划分。

E6含256正对、252同字异类交换错序、256末笔换类、6同序列异字OCR控制、6去尾字同序列兼容控制。相同笔型交换后描述未变的情形不制造错序负例。同序列异字在保留尾字时能被OCR区分，单列控制；隐去尾字时相同序列可兼容多个字形，应标兼容，不能标负。碰撞索引单独保存，跨分区不交换配对字符。

评分按冻结请求列表计算，不按返回列表缩小分母；保留 correct/incorrect/unknown/format_error/no_output/unqualified_gold/ambiguous_gold，另报原始输出状态，使真值不足与缺答可以同时被看到。无空间真值时不能输出0%空间准确率。主终点候选为未见字符 ESA 与重复笔型 PSRA；本开发集不支持正式结论。

工具提供按split、笔数层、条件、关系分表，以及按字符整体重采样的2000次、种子20261102的95% percentile bootstrap。正式检验、最小有意义收益与跨训练seed统计留待 pilot 和正式预算确定；开发区间不能支持显著性声明。
