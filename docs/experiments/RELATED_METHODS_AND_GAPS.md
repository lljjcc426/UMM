# H1-v3直接前作与方法边界

核查日期：2026-10-18。以下依据原文或官方资料；论文中的自报实验不等于本项目复现。研究缺口收敛为“从实际可见时间过程恢复状态”，同时保留强轨迹和像素对照。

| 工作／原始问题 | 核心机制与已有证据 | H1可借鉴设计 | 不能直接照搬／尚未证明 |
|---|---|---|---|
| [Show-o2](https://arxiv.org/html/2506.15564v2)：统一视觉理解与生成 | 语义与生成特征融合，理解与flow生成共享底座；已发布视频理解检查点。官方[视频脚本](https://github.com/showlab/Show-o/blob/main/show-o2/inference_mmu_vid.py)逐帧编码、14×14压缩后按时间拼接 | 固定融合表示，核查时间采样和空间压缩，先冻结诊断再讨论适配 | 通用问答成绩不保证实际笔画实例、方向或细完成状态；本批只用理解路径 |
| [Lance](https://github.com/bytedance/Lance)：图像／视频理解、生成与编辑 | 官方提供x2t_video及联合微调入口；视频推理环境要求CUDA，至少40GB显存 | 后续H1→H2共享模型的候选，先保证相同输入和评分 | 当前M5资源不满足；推理门槛也不能直接当作微调预算 |
| [VideoSketcher](https://arxiv.org/html/2602.15819v1)：顺序草图视频 | 几何合成先学绘制次序，七幅艺术家草图再迁移外观；支持笔刷条件和自回归扩展；两阶段消融体现顺序与外观的不同作用 | D0机制学习、同形换序、过程与风格分阶段 | 顺序视频生成已有直接前作；LLM偏好评价不等于中文规范逐笔正确率，也未证明读取实际错误反馈 |
| [Ordered Stroke Instance Prediction](https://arxiv.org/html/2609.02251v1)：静态字图恢复有序笔迹 | 自回归预测实例mask、框、置信及起终点，再恢复笔内轨迹；严格整字顺序67.03%，未见类别52.06%；给真笔画的Transformer排序92.27% | A实例定位与oracle／predicted分报；保留整字严格指标，定位错误会传播 | 输入为静态图，学习合理书写先验；无法据其成绩声称读取同终态不同实际历史；67.03%含实例匹配要求 |
| [InkSight](https://arxiv.org/html/2402.05804v4)：照片转数字笔迹 | ViT+mT5联合文字与ink token任务；包含中文训练；HierText人评87%合理描摹、67%似人工轨迹 | 阅读／书写的共享监督、可供H2使用的显式笔迹接口 | 合理轨迹与实际历史不同；描摹、OCR和人类相似性均不能替代实际视频顺序检验 |
| [Ketaba-OCR-LoRA官方卡](https://huggingface.co/HassanB4/Ketaba-OCR-LoRA)：阿拉伯手稿行识别 | 领域HTR底座再QLoRA；卡中r32、DoRA、RSLoRA，报告单模型blind CER0.088，六模型集成0.0819（逐行口径）；官方整库0.0938 | 任务匹配的领域预训练、参数适配、保留blind评价 | 模型卡的基础模型标识有简写／示例差异，集成收益不能归给单LoRA；静态OCR不验证时间事件，配置不能当作本任务最优 |
| [UniCalli](https://arxiv.org/html/2510.13745v2)：列级书法识别与图像生成 | 标准字体／书法双latent不对称加噪，MMDiT及框图支持文字、风格和布局；原文有识别、生成与消融评价 | 后续保留字形身份、布局与风格的联合监督 | 输出为静态书法，未验证实际运笔次序；宽泛“统一书法读写”已有前作 |
| [DiffInk](https://arxiv.org/html/2509.23624v3)：整行在线笔迹生成 | InkVAE加文字／风格latent分类监督，InkDiT生成整行轨迹；CASIA-OLHWDB2.0—2.2实验及消融 | 轨迹强基线；将任务监督作用于可用中间表示 | 文字／风格正则主要在VAE阶段；轨迹生成与视频观察不同，OCR质量不等同规范顺序 |
| [OnOff](https://arxiv.org/html/2608.03198v1)：在线轨迹与离线笔刷外观联合建模 | 六参数物理笔刷和可微渲染，连接轨迹、图像及机器人书写，原文报告生成与执行评价 | 后续执行器／外观分工及实例可追踪渲染 | 可执行轨迹不直接证明能读任意视频的实际过程；不能省略轨迹／生成专门方法的比较 |
| [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)／[Hanzi Writer](https://hanziwriter.org/docs.html)：规范字形与笔画动画 | 图形含实例路径与median；Hanzi Writer数据来自MMaH并支持逐笔动画；字典与图形来源许可不同 | D1实例监督、可控过程；选择大陆规则后逐字核对，按底层轨迹分组 | SVG动画顺序不自动等于所有地区规范；库代码许可不覆盖所有字体／数据；本批D0原创几何不下载分发D1 |
| [CASIA-OLHWDB](https://nlpr.ia.ac.cn/databases/handwriting/Home.html)：真实在线笔迹 | 官方按书写者划分训练／测试，记录在线点序列；可用于实际运动与字形分析 | D2真实次序、书写者分组，与规范分别存储 | 实际书写未必合规范；下载／分发须检查对应许可，当前没有导入或声称授权 |

本批贡献判断：冻结UMM＋新头只证明特征可读取。若清楚D0下像素法更可靠，需解释UMM在复杂实例绑定、真实视觉干扰或后续生成反馈中的必要性。读过程、帮助生成、统一训练有额外收益仍分别属于H1、H2、H3，不能互相替代。
