# H1-T7方法定义

## 同图目标区分监督

A保持T6原结构，mask为逐实例独立sigmoid，不使用实例间softmax。记真实像素实例为M_i，独有区域U_i=M_i减去其他实例并集；共享区域S为属于至少两个实例的像素。用16×16平均池化得到27×27面积权重u_i和s，t_i为完整实例面积标签。

对同图有序实例对(i,j)，正权重为u_i·1[s=0]，负权重为u_j·1[t_i=0]·1[s=0]。共享像素所在的整个原生格不进入区分损失，仍保留原mask监督。正负分别按自身权重归一化，各占一半；目标二值标签取t_i>.25，与实例IoU评分网格一致。若某侧没有独有区域，该实例对不参与。这样不会要求交点只属于一个实例，也不把仅同格、未同像素的局部区域强行设成互斥。

实例同类或粗位置距离≤.6时权重2，其余权重1；在全部有效有序对上归一化。L_target为上述加权BCE。A0使用原BCE+Dice+.1质量置信监督；A1只增加.2 L_target。质量目标为停止梯度的软IoU，沿用T6。规范ID、类型和粗位置都来自指定任务查询；没有事件日志或当前视频监督进入A。

采用共用Dev基础损失选checkpoint，完整新损失另存，防止两个选择目标不同掩盖比较。原始代码见`scripts/h1_target_contrast.py`。

## 事件表

L0保留T6原实现。L1的最终在线更新规则在T7-4根据Train/Dev固定；Test在此前保持锁定。所有时间区间采用(a,b]，相邻(a,b]与(b,c]可确定先后，不能因数值端点相接误判为同时。真实采样无法分辨的事件组与模型证据不足分开记录；后者不能直接标为物理不可恢复。

### L1-v1.1：Train/Dev固定的规则

全部阈值保持presence .5、start .5、新墨迹 .02。维护每实例unseen/candidate/confirmed/ambiguous、最近一次三信号都低的观察、上一观察的start+变化线索、首次检测和确认区间。只保留一帧起笔线索，不缓存原视频。

1. presence与至少一种start/变化信号过阈，才建立candidate。仅presence过阈记ambiguous，不当作已确认事件。候选可能区间从最近一次三信号均低到首次检测，表示为(a,b]；未见可靠初始阴性时左端为null。
2. 三信号同一观察一致，可立即确认该观察区间。presence首次延后，但上一观察已有start+变化、当前有presence+变化时，可用明确保存的上一帧线索收缩区间。若候选建立时已有presence+变化，下一实际观察presence继续过阈，也可确认原有可能区间；不会强制把宽区间变成单帧。
3. 缺少新增确认依据时继续保留候选。三信号随后均低时驳回候选，记录被驳回的全部候选、时间与理由。已确认事件不重排；后续存在信号冲突只记审计，不覆盖先前输出。
4. 预测实例掩码两两IoU≥.5时，涉及目标的确认暂缓并标uncertain_instance_binding。使用既有A输出，不添加新网络或质量阈值。合法交叉本身不被强制排斥。
5. 只对两个已确认且可能区间严格分开的事件建立关系：(a,b]与(b,c]可确定先后。非传递的区间重叠用最大未定团表示，避免把链式不确定强制变成所有事件同时发生。
6. 证据不足为uncertain_onset_detection；缺少输入前缀或观察跳步为insufficient_history；多个已确认事件落在同一观察区间时推断merged_onset_interval。这一推断仍依赖感知可靠性，L1不声称已证明物理不可恢复。需要检查过去观测或更密采样，不能把检测失败直接归为真实缺帧。

这些信号共享空间特征，其中presence/start来自同一M1；不能视为独立证据或相乘得到正确概率。规则是待检验的确定性假设。初版Dev重放后发现已完成笔画没有后续新增墨迹，故只修订持续存在的确认条件；不改变阈值，共尝试两版规则。初版与修订版全部Dev结果保留，见ledger_rule_amendment.json；测试解锁后不再修改规则。
