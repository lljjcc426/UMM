# T6：早期实际历史记忆（训练前固定）

研究问题：最近视觉、相邻变化、参考、查询和时间完全相同时，完整历史与在线事件表能否保留不同的早期真实顺序？H-T6-1检验局部信息限制，H-T6-2检验记忆，H-T6-3检验合并起笔的不确定性。既有T1—T5结果不修改，H1未通过，H2／H3不启动。

## 数据与信息控制

原创五笔D0：平行、横竖、交叉、折笔、近邻各类。20／8／20独立几何分组，data seed 20261019；每组correct、swap1、swap2、mergedA、mergedB，共240段；另2组三笔“三”8段仅诊断。训练20组每类4，开发前3类各2、其余各1，测试每类4。正确历史复用在两配对中，bootstrap按20个几何组（2000次，seed42）。全部源日志、派生观察和前缀随组划分。

源93帧、24fps、432RGB、宽13；固定索引0,4,…,92，共24观察。正常早期笔画第1/3/5观察出现、第2/4/6完成；交换早期事件，公共后缀从6开始。第4笔观察14/15/16/17为25/50/75/100%，第5笔20/21/22为25/50/75%，23完成。主决策15（第4笔一半）、20（第5笔四分之一）、23（完成）；最近8帧及其前驱全部相同，最近4也相同。三笔诊断前两笔早期交换、最后一笔14—17增长，20/23完成。

mergedA/B源帧1、2分别完成前两笔，固定采样帧4才共同出现；完整输入完全相同。输出完整event_order=null，但保留[0,1]未定组及它们先于后续笔画的关系。更多未来画面无法恢复已经丢失的先后。诊断和所有门槛允许在训练前读取像素／输入契约，锁定测试的学习模型成绩在dev选择完成后统一读取。

字节相等、一次内容哈希、缓存索引／张量精确相等均按任务书保存；不追加无关hash核查。像素读出使用独占实例区域，先于标签日志独立核验可观察性。模型输入白名单：实际RGB特征、参考特征、ID／类型／四分之一画布粗中心、真实时间戳；变体名、源顺序、精确mask仅标签或oracle。

## 固定模型与预算

Show-o2及编码路径复用T4，全参数冻结；CPU fp32 VAE、MPS bf16融合，27×27×1536；逐帧固定seed0，相同RGB复用同一缓存。按几何分块缓存，训练按需读取，避免全量fp32。旧T4 A+B先载入；若新增ID3/4在train/dev空间IoU不足.5的实例超过10%，从旧A+B继续一次共同训练。除此不按学习测试成绩决定重训。

A+B：AdamW lr.001、wd.01、batch8、seed42、最多12轮，无额外轮次；使用所有训练视频观察1—23的参考mask＋当前/变化监督，沿用T4质量置信loss。按最小dev loss选，不以测试门槛续训。所有方法共用同一冻结A+B。

M1普通头与M2因果头从seed42共同可匹配层初始化，沿用EventState结构和损失；AdamW lr.001、wd.01、batch8视频、固定12轮。每个视频24帧，监督所有观察1—23，批内平均，等样本暴露／更新数；无早停、无追加搜索。C=256维／2层／4头。源规范顺序不参与实际排序监督；起笔监督来自RGB可观察区间，同区间不排唯一序。M3以M2固定权重推理最近4/8帧，保留绝对时间和边界相邻差。M4用M1逐帧局部预测＋共享新增墨迹进入在线Ledger，无新增训练。M5正确可观察起笔区间＋正确区域，仅上界。M0正确区域＋RGB，仅上界。

Ledger阈值在训练前固定：存在概率≥.5、预测新增墨迹占该区域≥.02才确认首次起笔；出现但缺变化证据标记匹配不确定、不用规范补齐。相同区间多实例保留歧义；存储已确认事件，后续状态变化不覆盖早期顺序。不搜索阈值。M1/M2原单排序分数＋可观察置信结构不增加输出头；未知时其全部已见实例暂列未定，无法保证保留部分顺序，此项如实评分。区域oracle诊断只替换输入，复用同一个已训练头，不作为独立匹配训练上界。

## 评价、门槛与停止

Primary：每个决策40对均需两段真实顺序同时正确；逐段严格顺序分报。完整历史对最近4/8、三笔诊断对五笔、时间间隔和中间／最终状态分报。跟踪早期正确→后期错序。未知召回／错误接受、可观察回答覆盖、未定关系／已确认关系保留、高置信错误单列。Secondary：首错位置、动作类别和全部字段、状态/连续进度一致性、oracle区域差、推理时间、记忆量、参数与训练成本。观察置信度表示可观察性，不是答案置信度。

零训练门槛：像素和oracle Ledger清楚事件全对、合并事件保留局部未知、所有最近输入及B3决策特征严格相等、无标签／未来泄漏。失败先修代码和数据，停训练。新24帧先固定4train/2dev/2test的接口与资源检查，仅一次前向／梯度，不训练选参。

探索目标：配对≥.8、未知召回≥.9、可观察覆盖≥.9；不等同完整H1。Full胜Short只支持历史信息价值；Full还须直接比较Ledger。Ledger相近或更好优先显式记忆。两者都失败而oracle成功：REVISE视觉事件／实例绑定／时间／未知；不加深网络、不启动主干LoRA。简单Ledger接近oracle：停止堆叠时序网络，后续另注册真实困难条件。当前无依据进入H2／H3。

分阶段提交：T6-1协议／数据；T6-2零训练；T6-3接口／唯一空间适配；T6-4固定比较；T6-5分析，之后不追加训练。全部失败与曲线保留，既有权重不覆盖。
