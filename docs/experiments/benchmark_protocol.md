# 实验协议草案：过程正确性、风格与效率

这是建议的可执行研究协议，不是已经建立并跑通的模型排行榜。

## 1. 固定输入与输出

分别报告：
- T→轨迹；
- 字图→轨迹；
- T+风格参考→书写视频；
- 正确轨迹/掩码→书写视频（执行上限）；
- 模型预测轨迹/掩码→视频（完整系统）；
- 实际前缀→合法续写；
- 错误前缀→定位及离线重生成/在线失败判断。

所有基线得到相同文本、风格、规则、长度及控制信息。Oracle条件与预测条件分表。

## 2. 过程标签与不可观测性

每条样本预先指定规范与允许解集。笔事件包含笔画身份、字符身份、开始/结束、落笔/抬笔、方向和可见性。
视频帧率不足、手部遮挡或装饰覆盖时，可标`unobservable`；不可强制算成模型错误，也不能当正确。

只看最后一帧的OCR不能判别中途笔顺；单一轨迹距离混合顺序与几何。[HTR](https://arxiv.org/abs/2607.03422)、[VidScribe](https://arxiv.org/abs/2609.36598)与[VTR](https://arxiv.org/abs/2610.01499)的评价对象不同，不能混成一个排行榜。

## 3. 最低指标组

| 组 | 指标 | 注意事项 |
|---|---|---|
| 内容 | CER/AR、整字/整行全对 | 指明归一化、字符集和OCR版本 |
| 笔身份/顺序 | 序列完全匹配、编辑距离、首错事件 | 必须有实际事件识别或人工标注；自报计划不算 |
| 几何 | 对齐后的轨迹误差、目标区域覆盖 | 不可过度配准消除真实位置错误 |
| 运动/接触 | 方向、转折、抬笔、墨迹出现对应 | 轨迹方向与像素显示方向要一致 |
| 历史 | 旧笔消失/漂移/身份修改 | 结构保持不要求每个像素冻结 |
| 外观 | 风格一致、可辨识、纸墨自然度 | 与过程正确性分报 |
| 效率 | 首有效笔画、总时延p50/p95、吞吐、NFE | 包含预处理、渲染、检查与重试 |
| 显存 | 权重、激活、KV、解码峰值 | KV压缩倍数不能当总显存倍数 |
| 训练 | 标注量、GPU时、教师采样/评审 | 同数据与同计算分别比较 |

## 4. 测速控制

公开硬件、batch、精度、采样器、guidance、编译、warmup、随机种子、并行、分辨率、帧数/轨迹长度、参考长度。注明是否缓存模型、是否计入网络API延迟。

指标“有效吞吐”可定义为合格样本数除以完整耗时，但必须同时报首次成功率、最终成功率、拒绝覆盖率。不能只接受简单样本来夸大效率。

## 5. 公平归因矩阵

| 对照 | 目的 |
|---|---|
| 相同末帧，交换实际笔序 | 区分实际过程理解与背规则 |
| 固定文字前缀，改关键视觉状态 | 判断后续是否使用视觉证据 |
| 同面积无关纹理变化 | 区分语义必要性与显著性 |
| 正确诊断 / 模型诊断 | 拆开检测与执行 |
| 无反馈重采样 / 局部修复 | 区分额外尝试与反馈收益 |
| 原模型少步 / 专门训练少步学生 | 避免错误推断采样下限 |
| 普通缓存 / 事件缓存 / 理想缓存 | 判断任务机制而非预算差异 |
| 规则渲染 / 专门模型 / 外部VLM / 原生UMM | UMM必要性检验 |

## 6. 泛化和统计

把字类、风格、书家、渲染器、长度、二维布局、规则变体分别划分，不以“新句子”冒充“新字形”。预先指定样本量和重复种子；报告置信区间，保存全部失败样本。小提升不应省略方差。

## 7. 数据和隐私

不以用户上传匿名稿件的非公开数据做公共基准。真实书写数据许可、书法图像与字体许可分别审查。库内不包含字体文件、模型权重、原论文或受限数据。

`data/experiment_template.csv` 是空白记录模板。`scripts/stroke_metrics.py` 仅演示已标注ID序列的比较，不会从视频自动提取笔画，也不声称是经过验证的规范识别器。
