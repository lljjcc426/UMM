## 关键内容修订

| 项目 | 整合后采用的口径 |
|---|---|
| 研究优先级 | 实际笔画实例顺序和UMM额外价值为主线；效率保留为第二阶段 |
| InkSight | 训练包含中文；读写联合有直接前作，但去渲染不等于开放书写视频生成 |
| XMP-Font | 2022年已有笔顺预测器损失；监督静态字形，不代表监督实际时间顺序 |
| 层级双域HTR | 91.2为起点／数量／长度综合分，不能写成严格笔顺正确率 |
| 有序实例恢复 | 67.03%包含实例数量和几何匹配约束；不是纯排序准确率或完美视频裁判 |
| VidScribe / VTR-Bench | 已有手写演化因素与视觉反馈方法；仍需区分转录、结构与规范笔顺指标 |
| DiffInk | 保留此前公开代码核查：VAE阶段的识别／风格监督与DiT阶段的实际反传项分开；不把日志指标当作生成器训练损失 |
| UMM定义 | 任务统一与扩散生成方式不互斥；共享结构不自动证明理解—生成协同 |
| 修复定义 | 已发生的错序不能靠未来添笔消除；回滚需报告尝试次数和成本 |

主目录中的原文核查层级继承各来源记录；本次整理不把历史核查升级为新一轮全文阅读。对于原表合写的问题／方法或结果／边界，保留实际信息并明确字段边界，不补造未核读内容。
