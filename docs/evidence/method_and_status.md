# 文献整理与核查方法

## 记录与去重

`data/literature.json` 保存文献主数据。研究主张、方法、针对问题、结论和限制分别记录，并附原始来源、论文版本和核查范围。

同一研究按arXiv基础编号、DOI或规范编号归并；资源按具体实体归并。论文与其数据或工具可以分别登记，但资源不计作论文。首次整合的365条来源记录对应280条主记录，旧编号见[编号映射](../../data/record_aliases.json)；补充SteerVTE后第一轮主目录共281条；2026-10-19第二轮整合14条补录并新增32条基础研究后为327条；继续复核新增1个关联模型制品后为328条。`evidence_history` 保留不同记录的核查信息。

候选题录与正式文献目录分开。撤回研究及排除原因见[排除记录](../../data/excluded_records.json)，不作为结论依据。

## 核查范围

| 字段 | 含义 | 使用范围 |
|---|---|---|
| `historical_record_not_rechecked` | 继承既有记录，尚未重新核查原文 | 可作为阅读线索；正式引用数值前复查原论文及版本 |
| `primary_sections_read` | 已读取相关方法、实验章节或资源卡 | 支持所列章节/资源范围内的结论，不代表全文、附录、代码和权重均已核查 |
| `primary_abstract_read` | 已核查原始摘要或元数据 | 支持任务与方法概述，不支持摘要以外的实验细节 |
| `primary_metadata_only` | 仅取得官方索引或元数据 | 只确认来源和明确列出的信息 |
| `historical_record_unresolved` | 原始来源尚未成功获取 | 保留为待核线索，不视为已验证证据 |

`checked_on` 记录原文核查日期；历史记录的核查范围不会因重新整理而提高。表中未单独摘录的字段明确留缺，不自动补写作者主张。

## 结果与推断

- **作者报告**：论文在特定数据、版本及评价协议下的结果，不等于独立复现。
- **研究限制**：原评估未覆盖的能力或作者明确指出的问题。
- **待核信息**：原文、版本或指标含义尚未确定。
- **研究假设**：由文献推导、需要对照实验验证的方案。

OCR、WER、静态FID与轨迹DTW不能直接替代笔顺正确率。采样步数、token数量或局部缓存的下降，也不能直接换算成端到端加速或总显存收益。

未检索到完全匹配的研究，不等于该研究不存在；单个成功或失败样例不能代表总体正确率。正式出版信息、预印本版本与模型检查点应分别核对。

## 资料范围

研究笔记依据可公开访问的论文、作者项目、官方资源、公开样例，以及明确提供的四份附件。附件版本与公开版本分别说明；未找到公开对应来源的匿名稿只写研究分析，不加入公开文献主目录。论文全文、模型权重、字体及受限数据不随仓库分发，使用时遵循原来源许可。

`tests/` 检查文献结构、仓库内链接、已标注事件指标，以及受控像素观察器的顺序、方向与采样歧义，不评估生成模型。

## 第二轮新增证据层

`review_path`连接逐篇分析，`dataset/framework/architecture/metrics/baselines/experimental_conditions`保存已摘录的实验字段；空字段表示尚未摘录，不能自动填为无相关实验。`review_history`保留改写前记录，旧档案文件保留。

`review_depth=critical_sections_reviewed`只表示有针对已读章节的批判分析；`first_pass_only`仅为第一遍。它们均不等于核心三遍验收。当前333篇论文／研究中，327篇已完成所记录范围的核心三遍阅读及五项书面检查，具体版本、附录和代码范围仍见单篇笔记；其余6篇资料未齐，2026-10-25按用户要求停止跟进。完成证据见[台账](reading_ledger_2026-10-19.md)，停止范围见[说明](../reading/scope.md)。

五项书面记录曾包含未通过条目与历史资源条目，不能直接作为论文完成数。资源使用独立的公开制品协议审查，不套用论文三遍模板。本次主题与会议整理同步远端L184已有完成证据，原部分核查记录保留在验收历史字段。

[来源访问日志](../../data/source_access_audit_2026-10-19.json)单独记HTTP结果、落地页与正文候选、PDF及占位页，不能用来自动升级原文核查状态。arXiv有返回200但正文为空的转换页，DOI也可能只返回Redirecting；这两类均不当作已读全文。

## 会议与主题组织

[阅读总览](../reading/README.md)按六会议和七个研究问题组织已有笔记。会议身份依据原笔记中的出版方、官方目录或作者材料；正式归属、作者录用声明、Workshop／Findings／Demo等分别列示。投稿模板、引用他文及扩展稿前身的会场不能作为本记录录用依据。

会议身份与实际阅读版本分开：核实一篇预印本后来录用，不表示已逐项读过终版修订。每篇论文只有一个计数用主主题，跨主题联系写入[综合分析](../reading/synthesis.md)。配置与依据见[组织配置](../../data/reading_guide_2026-10-25.json)，生成结果见[结构化索引](../../data/reading_organization_2026-10-25.json)。
