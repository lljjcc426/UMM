# 来源、核查层级与结论使用方法

整理日期：2026-10-15。本库是研究笔记，不是论文排名，也不是模型实测报告。

## 三条来源链

1. `archive/` 保存用户此前 2026-10-13、2026-10-14 调研的**公开安全版**。历史“全文核查”是当时记录的状态，不代表本轮重新读完所有全文。
2. `data/literature.json` 每一行保留 `provenance`、`previous_evidence`、`verification`、`checked_on`。本轮重新核查的新增项有日期；继承项不虚填今天为全文验证日期。
3. `docs/handwriting/01_focused_update_2026-10-15.md` 为本轮重点专题；`docs/umm/` 把更早讨论过的 UMM 架构、协同、推理和效率重新组织为可检索的主题。

## 核查状态

| 机器字段 | 含义 | 允许使用的结论 |
|---|---|---|
| `historical_record_not_rechecked` | 继承已有表格，本轮未重新逐项验证 | 可作为阅读线索，数值正式使用前复查原论文及版本 |
| `primary_sections_read` | 本轮读取原论文相关方法/实验章节 | 仅支持写明范围的报告；不代表所有附录、代码或论文无误 |
| `primary_abstract_read` | 本轮核查原始摘要/元数据 | 支持任务与高层机制，不支持额外细节或自填数值 |
| `primary_metadata_only` | 官方索引或元数据可见，正文访问未完成 | 只确认来源线索及明确显示的范围 |
| `historical_record_unresolved` | 历史线索，本轮原始页未成功获取 | 保留并排入复核，不当作本轮证实 |
| `withheld_private_source` | 来源是用户提供的匿名稿件 | 公共仓库只留占位，不公开原稿、题名或结果 |

## 六列表格口径

- **声明**：作者提出的主张，不能写成普适事实。
- **方法**：输入、表示、训练/推理机制、输出；“统一”应说明统一了什么。
- **针对问题**：该工作定位的实际瓶颈。
- **结论**：作者在具体协议下报告的结果，非本次复现。
- **缺口**：`【边界】` 指评估未覆盖或作者已承认；`【待核】` 指证据未确定；`【推断】` 是本库提出的待验证假设。

## 不做的推断

- 未找到论文 ≠ 不存在论文；没有专用指标 ≠ 模型一定失败。
- 可读文字/OCR/WER ≠ 正确笔顺；DTW同样混合几何与时间误差。
- 原模型减少采样步数的表现 ≠ 专门训练少步模型的上限。
- NFE下降 ≠ 端到端等倍加速；KV压缩 ≠ 总显存等倍降低。
- 单个演示/作者挑选成功例 ≠ 某语言、书体或模型的总体正确率。
- arXiv年份 ≠ 会议录用年份；名字中“unified” ≠ 理解—生成统一大模型。
- 代码仓库可访问 ≠ 权重、数据、完整复现脚本均可用。
- 历史文件和本轮调研观点存在变化时，保留来源和变更记录，不静默覆盖历史。

本次没有调用视频模型、UMM或笔迹生成权重进行采样或测速。`tests/` 仅测试整理脚本与演示性事件指标，不是模型评测。
