本批19项存量研究的结构化原文分析见[新增ID清单](../../data/third_review_batch_2026-10-20.json)和[逐篇笔记](../reviews/README.md)。以下问题定位到已读来源，尚未通过独立模型实验验证；保留作者解释或版本修正的可能。

## 需要澄清的实验与实现

| 研究 | 原始证据 | 可以得出的结论及待核项 |
| --- | --- | --- |
| [InkDiffuser](../reviews/B03.md) | HTML式11–12与固定版本代码的形态学算子不同；parser默认与正文不同；所查树缺训练入口导入的模块 | 先对齐PDF、训练命令、代码与权重。缩放sigmoid的绝对值有tau上界，tau趋零时不能一般逼近局部min/max；代码的log-mean-exp是另一表达。不能据静态检查推断实际论文实验未发生。 |
| [DiffMath](../reviews/B09.md) | 正文与附录的VAE/DiT学习率、batch、步数和loss权重不同 | 分列两套条件，未确认采用哪套前不作可复现性承诺。轨迹输出有先后信息，规范笔序仍未评价。 |
| [Layout Stroke Imitation](../reviews/L004.md) | Table3加入MS后FID/PSNR/MSSIM均较layout-only变差，正文却称后两项改善；正文6小时与Table4的24小时冲突 | layout条件效果与MS效果分开归因；时间和硬件需原配置解释。 |
| [StrokeBank](../reviews/L005.md) | 已视觉核对PDF第4页式5：距离约束方向与随后的hinge不一致；Table1映射错误率下降 | 可记录结果；实际QP需代码确认。人评Xing58.5%、ShouJin49.6%不能统一描述为与随机等效。 |
| [FontDiffuser](../reviews/L019.md) | Table3部分像素/感知指标改善，FID由8.1153升至8.5352 | 报告多指标取舍；不使用“全部指标提升”。 |
| [FlashU](../reviews/C04.md) | GenEval7B .76→.72、延时22.74→11.82秒 | 支持所测条件下约1.92倍加速，伴质量变化；校准和模块开销均需计入。 |
| [UniCache](../reviews/C05.md) | BAGEL主要分数接近，SenseNova GEdit却6.691→6.130；预算针对历史KV | 不能推广所有任务无损，也不能将KV减量当整体显存降幅。 |
| [RecA](../reviews/C06.md) | .86与.90结果涉及不同额外SFT条件；已有重建的架构存在无效或反效 | 分开数据、架构与训练顺序，保留负例；静态重建的收益不能直接推断时间理解收益。 |
| [UMM-Reflection](../reviews/C07.md) | 联合训练优于单头，但有外部轨迹SFT、verifier奖励及最多3轮编辑；删reward项时初始分数也变化 | 同时匹配数据、训练与推理预算，测试联合参数的具体贡献；轮内增量与最终分数分别报告。 |

## 知识盲区与集中学习清单

| 概念 | 在文献中负责什么 | 本轮能解释的部分 | 后续需要补齐 |

| GRPO与flow-SDE | 将轨迹奖励分配给文字与图像transition | 同组标准化优势与PPO clip/KL约束；detached初始图仍会受共享参数变化影响 | probe/验证器依赖、奖励方差、同预算外部critic对照 |

| 字形拓扑与事件规范 | 描述空间结构或时间顺序 | 无序笔画计数、连通性和最终OCR均不能唯一确定历史 | 不同文字专家规范、重描不可观测性与多种合法顺序 |
