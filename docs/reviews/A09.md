## 2. 现有方法不足（Motivation）

## 3. 核心创新（Contribution）

SDT用互补对比目标分离writer-wise与character-wise风格。

## 4. 方法流程（Method）

输入与输出：标准字形+15幅作者参考图→在线字符轨迹。

方法框架与模型结构：Transformer风格编码/解码，作者与字符两路风格；512维、8头、编码器2层、风格解码共4层。

数据集与分布：CASIA1.0–1.2约370万/1020作者；ICDAR2013的60作者测试；RDP epsilon2使平均约50点。
