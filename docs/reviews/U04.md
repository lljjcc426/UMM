## 第一遍：三句话定位

已有困难：原Janus StageII前2/3的T2I步骤用ImageNet类别名学像素依赖，浪费densecaption训练；真实生成数据噪声/质量限制稳定美学，1.5B容量限制表达。已有编码分离可保留，改进针对训练/数据/scale，不能将继承结构再次记作Pro独立创新。

作者提出：StageI延长ImageNet训练、StageII去ImageNet专注densecaption；StageIII understanding:text:gen由7:3:10→5:1:4；理解预训+90M，生成+72M合成美学，统一预训real:synth1:1；扩大1.5B→7B。未提出独立新注意力/扩散机制。

目前证据：T3 Janus→Pro1B→Pro7B：MMB69.4→75.5→79.2、MME-P1338→1444→1567.1、MM-Vet34.3→39.8→50；POPE87.0→86.2→87.4，1B并非全理解指标提升。T4 GenEval.61→.73→.80；7B六项.99/.89/.59/.90/.79/.66，SD3M overall.74且counting.72高于Pro.59，不能称每子项更优。T5 DPG79.68→82.63→84.19；SD3M84.08，差.11且未给CI；Dalle3 global90.97高于Pro86.90。可支持特定报告协议下系统改善。

## 1. 研究问题（Problem）

扩展Janus静态多模态理解与文本到图像生成，研究调整三阶段训练、扩大高质量数据和LLM容量后，指令跟随/美学/理解性能如何改变；输出为答案或384²图，不是笔顺/视频。

## 2. 现有方法不足（Motivation）

原Janus StageII前2/3的T2I步骤用ImageNet类别名学像素依赖，浪费densecaption训练；真实生成数据噪声/质量限制稳定美学，1.5B容量限制表达。已有编码分离可保留，改进针对训练/数据/scale，不能将继承结构再次记作Pro独立创新。

## 3. 核心创新（Contribution）

StageI延长ImageNet训练、StageII去ImageNet专注densecaption；StageIII understanding:text:gen由7:3:10→5:1:4；理解预训+90M，生成+72M合成美学，统一预训real:synth1:1；扩大1.5B→7B。未提出独立新注意力/扩散机制。

## 4. 方法流程（Method）

输入与输出：图像→SigLIP语义编码+2层MLP理解adaptor，文字→BPE，进入共享AR Transformer→答案；生成文字前缀→共享LLM→独立imagehead预测576视觉离散码→LlamaGen VQ16 decode384²。训练图像另走VQ编码与2层genadaptor，实际Fig3已看。

方法框架与模型结构：DeepSeekLLM1.5B/7B共享backbone，SigLIP-Large patch16/384、生成VQ码本16384/downsample16，理解/生成编码分离沿用Janus。T1 embedding2048/4096、layers24/30、heads16/32、ctx4096、词表约100K。HF7B config vision1024→4096、gen8→4096，imagehead16384，vocab102400/max_position_embeddings16384；后者为配置上限，训练/README context仍4096，不据此声称训练16K。1B标签实际LLM1.5B。

数据集与分布：StageII额外约90M理解样本含YFCC及Docmatix表/图/文档；StageIII另加DeepSeekVL2 MEME、中文对话等，不合并成全部90M都SFT。生成额外72M合成美学，real:synth1:1只指统一预训；Ref43为vivym/midjourney-prompts提示资源，不足证明所有合成样本来源/生成器/许可。完整数量组成、清洗、去重和原始样本清单未公开到可独立核验程度。

## 5. 实验结果（Experiments）

主要基线：原Janus1.5B与Pro1.5B/7B、TokenFlowXL13B、MetaMorph、Show-o、Chameleon、Emu3、LLaVA等理解统一模型；生成DALLE3/SD3M/Transfusion/SDXL等。LLM参数数不含所有vision/tokenizer等资源与预训练成本，不可视为严格等预算。Pro1.5B比Janus1.5B仍同时改策略/数据；Pro7B比Pro1.5B还变SFT步数。

关键指标：理解GQA/POPE/MME-P/SEED/MMBench/MM-Vet/MMMU；静态生成GenEval六类别与DPG1065denseprompts。主文无OCR/笔顺/视频/真实执行指标，定性简单文字图不等逐字符正确率。多seed/CI、prompt改写、候选选择、生成采样及裁判配置未完整披露，默认示例不得当论文评测协议。

实验条件：图像384：理解长边缩384灰127pad，生成短边384中心裁长边。StageI/II/III lr1e−3/1e−4/4e−5恒定，AdamW β.9/.95、WD0/clip1、warm600/5000/0，batch256/512/128。T2计划steps20K/360K/80K(1.5B)或40K(7B)，§3.1 StageII实际270K早停；不可用360K作为已执行。训练HAI-LLM，16/32nodes×8A10040GB=128/256卡，约9/14天（继承LLM/encoder预训另计）。StageII冻结两encoder，StageIII解冻理解encoder。固定1daa72f README Pro生成示例CFG5/T1/16并行/576码，根generation_inference.py默认旧Janus，不可原样声称Pro推理。

结果及解释：T3 Janus→Pro1B→Pro7B：MMB69.4→75.5→79.2、MME-P1338→1444→1567.1、MM-Vet34.3→39.8→50；POPE87.0→86.2→87.4，1B并非全理解指标提升。T4 GenEval.61→.73→.80；7B六项.99/.89/.59/.90/.79/.66，SD3M overall.74且counting.72高于Pro.59，不能称每子项更优。T5 DPG79.68→82.63→84.19；SD3M84.08，差.11且未给CI；Dalle3 global90.97高于Pro86.90。可支持特定报告协议下系统改善。

消融实验：全文无逐项数据×训练策略×模型规模受控消融，也无独立的7:3:10与5:1:4对照表。T3–5同1.5B跨版本可排除LLM规模变化，仍混合数据/日程/encoder适配；1B与7B的模型变化同时伴III步数80K/40K。§2称更快收敛/合成数据更稳定未提供量化独立曲线或方差，不能当作已验证机制归因。书面验收解释这种证据缺口，不补造消融。

所有分数均为作者报告；条件、版本和样本数不同的数字不得直接排名。

## 6. 局限与疑问（Limitations）

384²与VQ重建限制OCR/微小脸和细节是作者明确局限；主表未量化文字生成或规范笔顺。数据、encoder预训、参数和采样可比性不足，缺正交消融/CI，.11DPG差不可无检验称显著。HF元数据MIT与正文DeepSeek模型许可范围不同，代码/权重许可要分别读；当前卡/config不能倒填原文训练。未审完整trainer/评测器/权重或执行。

## 7. 我的思考（Insights）

优势假设（本仓库分析，尚未验证）：在同语义/静态图像分布、densecaption条件和扩展预算下，更多高质量合成可减少低质监督、将像素依赖提前至冻结LLM阶段可增加StageII有效描述训练，scale可能增强组合跟随。原文支持整体系统差异，未分离这三种机制；不保证规范书写时序或所有指标。

可证伪实验（建议方案，尚未运行）：固定LLM/视觉encoder/VQ、总token与计算，训练策略×数据质量/数量完整因子；1.5/7B分别同IIIsteps与同总预算比较，独立validation挑比例/采样，报告收敛方差和达到同质量耗时。共享最终checkpoint双任务、相同原prompt/重写/CFG/候选策略/分辨率和多seed，按GenEval子项/中文OCR与复杂度分层，公开协议及CI。书写领域另加事件/帧观测/执行基线；全部未执行。

这两项分别回答“在什么任务/分布/指标下有优势”与“如何验证”；上文问题、动机、贡献回答前面三个研究分析问题。
