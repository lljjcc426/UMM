## 4. 方法流程（Method）

输入与输出：原始HDF5+MarkWrite pen/plus报告→字/部件/笔画统计和可视图；本次下载的xlsx是按字符汇总数据，不是50400条原始轨迹。

方法框架与模型结构：batch_summarise_all.R从data/HDF5取trialvars、从data/Reports合并两报告；lpmm=200为空间每毫米采样单位，不能和采集200Hz混同。batch_funcs按stroke首末点算dur/前一笔end到当前start算rt_rel，欧氏点距sum/lpmm算mm长度、按pressure均值取整。

数据集与分布：OSF公开节点含Psychopy.zip约99.1MB、Data两xlsx(1.5MB/12.76MB)、R两脚本和分析HTML。已读小xlsx五表：VariableCorrelations1200×14、CharacterAnalyses1200×25、RadicalAnalyses1140×21、StrokeAnalyses1200×20、Hierarchy3540×28(均不计表头)。
