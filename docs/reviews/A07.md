## 1. 研究问题（Problem）

复杂字符的离线到在线恢复如何同时评估顺序和几何？

## 2. 现有方法不足（Motivation）

## 3. 核心创新（Contribution）

提出AIoU和LDTW，并用双流解析编码器/全局追踪解码器恢复长轨迹。

## 4. 方法流程（Method）

输入与输出：单字图像→有序坐标轨迹。

方法框架与模型结构：PEN-Net的双流图形解析编码器+全局tracing decoder。

数据集与分布：中文CASIA-OLHWDB1.1；英文52类；日文Nakayosi训练/Kuchibue测试；Tamil156类。

## 5. 实验结果（Experiments）

主要基线：DED-Net、Cross-VAE、Kanji-Net。

关键指标：AIoU、LDTW及原文其他三种指标；AIoU降低笔宽影响，LDTW按对齐路径长度归一化。

实验条件：坐标归一至[0,64)，在线渲染为离线；batch512/Adam/lr.001；中日500K步，英/Indic200K步；RTX3090。

结果及解释：原Table1比较四语种，支持复杂字形恢复；本卡不抄未逐项核对的分数。

消融实验：双流解析与全局解码的独立贡献仍需完整消融表核对，未宣称三遍读完。
