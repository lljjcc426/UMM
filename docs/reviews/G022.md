## 4. 方法流程（Method）

输入与输出：输入是已有文献、理论与各论文报告；输出为分类、通用前向/逆向机制和研究方向。实际核看p3 F3：图像沿前向扰动到噪声，逆向通过估计score/噪声生成样本；噪声时间不等真实书写过程，逆过程从先验生成新样本也不保证找回某个原图。无综述自训练的输入输出协议。

方法框架与模型结构：DDPM离散高斯Markov链，alpha=1−beta，文中beta_hat=prod(alpha)对应常用alpha_bar；噪声MSE经重参数化得到逆均值。NCSN学习各sigma平滑分布score，annealed Langevin采样；SDE dx=fdt+g dW的逆漂移f−g²score、从T到0，负dt与噪声sqrt(abs(dt))配套。U-Net/残差/attention是被综述架构，不能理解为三个互斥网络。DDPM原文称unmasked PixelCNN++式U-Net/WideResNet，不能因简写PixelCNN++就误判其为因果像素AR网络。

数据集与分布：表1列各被综述工作的数据，不存在综述统一训练/测试集。自然图含MNIST/CIFAR10/ImageNet/LSUN/CelebA-HQ/FFHQ/COCO/DrawBench，视频含BAIR/KTH/UCF101/Kinetics/模拟环境，医学含BRATS/fastMRI等。训练与评估数据在表中未统一区分，不能把一行所有数据都当训练集；没有字符顺序/真实动作数据的统一实验。

## 6. 局限与疑问（Limitations）

固定2023稿的覆盖边界不含后续DiT/flow/统一模型和大视频模型。三类关系有交叠，SDE是连续描述而非必然不同骨干；各任务/多任务行也非互斥。跨论文速度倍数和无条件稳定性/多样性泛称缺统一统计。AppA Eq17明确负loglikelihood≤变分目标，故该量是负对数似然上界/对数似然下界，正文“negative log-likelihood lower-bound”的文字不准确；Eq15中间积分写p(x1:T)而随后用条件分布，也应按条件期望理解，不照抄缺失条件。文献归属错误和未给系统检索协议使“comprehensive”不能当零遗漏保证。
