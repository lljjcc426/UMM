## 1. 研究问题（Problem）

能否在离散词元/像素空间定义可训练的概率流，直接匹配从源到目标的路径，并统一去噪、噪声预测、调度与corrector采样？

## 2. 现有方法不足（Motivation）

连续空间速度不能直接加到类别索引；现有离散扩散/掩码方法的训练、采样和路径常捆绑，MaskGIT按置信度解mask并非无偏路径采样。需要构造满足行和0、非对角非负的离散概率速度，而非把类别编号当连续坐标。

## 3. 核心创新（Contribution）

条件product概率路径经source-target耦合混合成联合边缘；后验平均条件速度得到generating probability velocity，CE学习denoiser。给出通用mixture权重速度、denoiser/noise参数化和forward/backward corrector；特殊全mask路径的denoiser可不依赖t。理想后验/小步结论不保证有限网络及有限步采样精确。

## 4. 方法流程（Method）

输入与输出：源all-mask或uniform词元/像素、可选可见前缀→并行离散序列或32×32RGB图像；每坐标按δ当前+h·u分类分布跳转。N维path条件独立不代表边缘词元互相独立；模型读取整段。词元位置的序列顺序与生成迭代次序分开，未评价规范笔画或视频。

方法框架与模型结构：D=[d]^N；Eq9路径(1−κ)δx0+κδx1，Eq10另加uniform。U耦合独立源目标，C耦合把目标部分可见/前缀作为source。Eq24 u=κdot/(1−κ)(p1|t−δ当前)，Eq25反向κdot/κ(δ当前−p0|t)，CE Eq28学后验。Corrector αuf−βub：α−β=1随pt生成，=0固定t保分布。Prop6时间无关仅全mask额外符号且目标不含mask的Eq7/9。150M DiT12层/12头/768和1.7B48层/24头/1536、RoPE/drop.1；图像113M UNet，257类×96embedding、RGB拼288通道，无颜色几何先验。

数据集与分布：150M在OpenWebText；1.7B用作者称与Llama2相同mix，code模型用CodeLlama mix，精确语料比例/训练token需更多配置。无条件1024token；条件测试OWT1000前缀，另HumanEval/MBPP1shot。CIFAR10原始32×32×3离散颜色+mask，无VAE。后续官方flow_matching示例FineWeb-EDU/WikiText103属于另一训练协议。

## 5. 实验结果（Experiments）

主要基线：同规模AR、Lou/Campbell等离散扩散、Savinov/Austin/Han，图像MaskGIT；条件大模型Llama2/3规模不同。代码Oracle length使用GT EOT位置，不作无特权基线。路径/耦合、训练与推理scheduler矩阵、corrector/temperature消融；搜索预算按模型分列。

关键指标：生成困惑度以Llama2/Llama3/GPT2评生成文本，非heldout真实likelihood；token entropy仅序列内词元多样性。代码Pass@1/10/25，CIFAR FID50K、NFE；延迟与吞吐分开。Table5 double precision分类采样显著改质量/entropy，采样精度是实验条件，entropy≥6为作者经验阈值。

实验条件：Adamβ.9/.999、peak3e−4/2500warmup；正式AppG1把batch4096/1.3M和batch512/400K均写作big models，存在分配歧义，未擅自填小/大对应。CIFAR Adam1e−4/b512约300K/drop.4。Cubiccorrector网格a,b各7值×α5值×temp3值；linear比较η6值×temp，搜索预算不同。无温度/无corrector的T2与T3增强采样分列。A10080GB单卡HumanEval b1延迟。固定官方库11568d37的FineWeb示例1Msteps/b512/AdamWβ.9/.95/WD.03，README8H100约380K/24h，不能用来补原论文歧义。

结果及解释：T2 1024NFE Eq9 Llama3生成PPL33.8/entropy7.2对AR54.8/7.1；Eq10为31.9/7.1。但T5 double precision Eq9 101.3/8.0、Eq10 100.5/8.0对AR54.8/7.1，排名改变。T3 C耦合256/512NFE Llama3PPL10.0/9.7优U11.2/10.3。T4 code HumanEval Pass1 FM6.7低AR14.3，oracle11.6仍低；MBPP6.7低17.0。CIFAR最佳FID3.63需1024NFE/调参，低NFE MaskGIT有优势。AppF256NFE19.97s对AR50.94s约2.5倍，512NFE延迟接近；作者明示AR KV缓存吞吐更好。

## 6. 局限与疑问（Limitations）

Theorem4固定t stationary证明采用单坐标转移、完美后验、0<t<1/正系数/足够小h，遍历收敛另需不可约与非周期；并行Eq12只具小h一致性，非任意有限步精确。Mask无corrector可跳过不变state且NFE≤N，不推广remasking。h必须保证概率非负，端点/自适应步增NFE。训练资源/模型batch歧义、代码任务落后及分类精度敏感均限制强claim。当前官方库使用先采x1、1−exp(−hλ)跳转与末步直取x1，不与论文δ+h·u逐行等同，未独立运行。

需继续追问：该局限是否已被其他研究解决？当前笔记的假设在未完成追引与对照前不计作新课题。

## 7. 我的思考（Insights）

优势假设（本仓库分析，尚未验证）：当目标本身为离散事件/token，后验可靠且并行更新有足够算力，路径/耦合/重掩码可改善质量延迟权衡；对于笔事件可比较类别预测，但合法笔顺、几何连续、接触/因果约束需额外定义，现有图像或语言PPL不能推出优势。

可证伪实验（建议方案，尚未运行）：同tokenizer/训练tokens/参数/FLOPs和采样精度，比AR缓存、MaskGIT、离散FM/扩散；固定验证集调scheduler/temp/corrector并报搜索开销，PPL+entropy+任务Pass与总延迟/吞吐。笔事件比较合法顺序率/短笔Recall/事件数量及RGB重建；全mask时间无关与uniform源、有限h/重掩码分别验证，不把理论条件删掉。

这两项分别回答“在什么任务/分布/指标下有优势”与“如何验证”；上文问题、动机、贡献回答前面三个研究分析问题。

能否在离散词元/像素空间定义可训练的概率流，直接匹配从源到目标的路径，并统一去噪、噪声预测、调度与corrector采样？——作者采用条件product概率路径经source-target耦合混合成联合边缘；后验平均条件速度得到generating probability velocity，CE学习denoiser。给出通用mixture权重速度、denoiser/noise参数化和forward/backward corrector；特殊全mask路径的denoiser可不依赖t。理想后验/小步结论不保证有限网络及有限步采样精确。；可采信范围以第5–6项为界。
