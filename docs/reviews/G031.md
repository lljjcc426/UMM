## 1. 研究问题（Problem）

用可诊断的维度评价视频生成，并检查与人工判断的一致性。

## 2. 现有方法不足（Motivation）

单一FVD难以指出模型问题，主观质量也由多个维度构成。

## 3. 核心创新（Contribution）

16维prompt/evaluator体系及逐维人类偏好数据。

## 4. 方法流程（Method）

输入与输出：文本视频模型生成结果→逐维分数和比较；本工作为评价框架。

方法框架与模型结构：DINO/CLIP/RAFT/ViCLIP/MUSIQ等不同视觉模型服务不同维度。

数据集与分布：每维约100提示；四类生成模型输出，WebVid检索参考与人工配对标注。

## 5. 实验结果（Experiments）

主要基线：LaVie、ModelScope、VideoCrafter、CogVideo；Empirical Max/Min、WebVid-Avg是参考而非生成器。

关键指标：主体/背景一致、闪烁、平滑、动态程度、空间等16维及人工对齐。

实验条件：每prompt采5组，四模型每组6对；视频顺序随机。WebVid参考取2秒、8fps、top5检索。

结果及解释：Table1显示维度间权衡：例如CogVideo平滑96.47%但dynamic42.22%；高平滑不等于足够运动。

消融实验：维度及人工对齐、内容类型分析用于检验评估设计；没有新增生成器消融。

所有分数均为作者报告；条件、版本和样本数不同的数字不得直接排名。
