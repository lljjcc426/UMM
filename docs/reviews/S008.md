## 1. 研究问题（Problem）

从人类写数字参考、机器人观测和指令联合预测机器人视频及动作。

## 2. 现有方法不足（Motivation）

仅视频不直接给可执行动作，仅动作缺少直观未来状态；跨人/机器人视角且时间不逐帧对齐。

## 3. 核心创新（Contribution）

Wan2.2TI2V5B视频DiT与30层ActionMoT共享联合去噪，公开checkpoint、归一化统计及训练配置。

## 4. 方法流程（Method）

输入与输出：query+人类头视角参考+机器人三视角起始图+54D proprio→9帧三视角未来视频和32×54绝对动作；仅0–9数字。

方法框架与模型结构：视频Wan2.2TI2V5B；action_dit dim1024/FFN4096/heads24/layers30，自定义投影源码未提供，不能据1024不整除24直接认定实现错误。full_ref=true、bridge_exclude_full_ref=true、mask_v2，条件参考与目标动作共享MoT；视频/动作loss权重各1。

数据集与分布：487 teleop episodes，439训练48验证；896人类ego参考。按任务数字一一配对参考episode，不保证逐帧或几何对齐。人类69帧/10采样等间距、灰底pad；机器人3视角grid最终384H×320W；原33帧→目标9，action/video ratio4。

## 5. 实验结果（Experiments）

主要基线：卡片未给video-only/action-only、去参考或错参考、专家动作与其他VAM匹配对照；不能将日志损失解释为共享协同优越。

关键指标：日志loss、actionMSE/MAE、videoMSE/PSNR/SSIM/LPIPS；没有汉字笔顺、笔尖接触或机器人成功率。

实验条件：12500steps/lr5e-5/wd.01/warmup500/clip5/bf16；每GPU batch1、global16、acc1、proprio_dropout.1。global16不能单独推出16卡硬件。需要匹配Wan VAE/T5/tokenizer和自定义代码；HF只有配置/权重，不构成完整独立推理包。

结果及解释：固定版本模型卡报告20个验证样本：总loss .278802=video .146057+action .132745；write_zero action MSE3.898803/MAE.801526，video PSNR16.28/SSIM.581/LPIPS.2252。属于作者checkpoint快照，未运行或验证部署效果。

消融实验：无公开匹配消融；需要动作/视频损失互去、共享/分离、同/错参考等预算实验。

所有分数均为作者报告；条件、版本和样本数不同的数字不得直接排名。
