## 1. 研究问题（Problem）

让一个视觉tokenizer兼顾语言对齐语义与可重建离散表示，分别接LLaVA理解、LlamaGen图像生成，并验证统一图文AR模型UM3的可行性。研究静态图像/文本，不提供书写视频、笔画事件或规范笔顺。三套下游实验不能合并成同一模型在全部任务上的成绩。

## 2. 现有方法不足（Motivation）

重建codec保留像素但语义弱，对比encoder有语义但不可直接解码；联合训练时梯度量级不同、STE影响及LPIPS/GAN显存与大batch对比学习冲突。解决训练兼容性不等于证明所有目标无取舍，量化前特征强也不能证明量化码同样适合理解。

## 3. 核心创新（Contribution）

BSQ球面二值量化与MLP前后瓶颈；阶段I以重建MSE/量化/图文对齐大batch联合训练，阶段II冻结视觉encoder、去文本encoder，仅调量化瓶颈和decoder并加LPIPS/GAN。正文采用先分别训练单目标、按收敛loss反比选固定权重的post-hoc方法，明确放弃在线adaptive梯度权重；摘要dynamic需受正文定义限定。

## 4. 方法流程（Method）

输入与输出：图像patch→ViT含CLS：CLS对比文本encoder的全局特征；patch经MLP降维、L2归一、BSQ符号量化、MLP升维、ViTdecoder恢复像素。LLaVA取倒数第二层连续特征→projector→Vicuna；LlamaGen预测离散码后解码；UM3混合文本/图像序列，冻结tokenizer、共享AR但文本/视觉分别softmax。实际F2、完整T2、T3a与T6核看。

方法框架与模型结构：B16/B8在256²、L14在392²；隐式码本28bit=2^28角点，模型规模表列B encoder87M+decoder87M+quantizer约1M，L304M+304M+约2M。初始化MIM/EVA-CLIP加CLIP文本encoder；非从零全部成本。UM3 Llama3式1.5B、QKnorm、新视觉embedding/head均值初始化；公开7blob实现仅tokenizer，未核实28bit码如何打包/分组进入UM3有限视觉词表，不能猜为两个14bit子token。HF group_size=1是量化实现设置，不直接等于下游AR词表定义。

数据集与分布：Tokenizer DataComp1B；LLaVA558K对齐/665K指令。T1图像数据列LAION-COCO4M/600M、CC12M6M/12M、SA1B11M；正文§5.1与附A使用5M LAION子集、5M+11M=16M，T7生成表却15M，数量/过滤版本未统一。UM3 DCLM300B文本、CC12M+SA1B约18M/10B图像token（表中6M+11M约17M，勿强行等同）。这些为暴露/子集描述，非新增独立样本数；历史encoder预训练另计。

## 5. 实验结果（Experiments）

主要基线：CLIP/OpenCLIP/EVA-CLIP/SigLIP、VQGAN/MoVQGAN/BSQViT/SD-VAE/OpenMAGVIT2/VILA-U等codec；同LLaVA协议CLIP替换；LlamaGenXL对比VQGAN/BSQ，后者15M而VQGAN50M图，非完全同数据；UM3对照原Llama3.2约1.4B、ZeroCap、LlamaGen。跨骨干/分辨率/预训练不同的大表不单独识别机制因果。

关键指标：Tokenizer ImageNet1K-val零样本top1、rFID/PSNR/SSIM；线性探测有额外监督。CR=24*p²/bit是固定宽度名义压缩比，不是实测文件熵编码体积。LLaVA VQAv2/GQA/TextVQA/POPE/MME/MMVet；LlamaGen gFID/CLIPScore/GenEval/DPG；UM3五语言基准、COCO Karpathy BLEU4/METEOR/CIDEr与COCO30K gFID/CLIPScore。rFID重建与gFID生成分开，所有静态指标不能验证时间顺序。

实验条件：T3消融B16短2B样本而非所有主表完整预算；αr:αa=1000:1，阶段II重建/量化1、LPIPS/GAN .1。附T8明确B8：阶段I LAMB/β.9,.95/wd.05/clip5/b65536/120Kstep，视觉2e-4、文本2e-5、decoder2e-3；II AdamW/clip1/b16384/120K，encoder0、decoder及disc1e-4，warm2000。I表曝光约7.86B与概述4B不能不加区分合成同配置。UM3 AdamW/lr1e-4/cosine/wd.1/clip1/b512/context4096/600K/warm2000；10K内text:caption:generate从60:1:3退至12:1:3，采样temp1/topp.95。未核完整训练硬件/多seed成本。

结果及解释：T2 B16零样本74.3/rFID3.21优于BSQ3.81，但PSNR23.16<24.12、SSIM.6286<.6638；B8 rFID.70/CR54.8需更多空间码；L392零样本79.1>VILA78、CR168=21的8倍，但rFID1.46劣于1.25。T4 QL392相对CLIP392，MME1498.3>1484.9，VQA78.3<79.1/GQA61.8<62.3/Text55.2<55.4/POPE86.1<87.5。T7 LlamaGenQLIP GenEval.48/DPG78.17，BSQ.31/34.03，支持该任务改进。UM3五语言项全低于Llama3.2：ARC34.30<34.90/Hella45.35<48.70/PIQA74.65<75.95/SIQA43.09<43.50/Wino54.22<61.48；gFID44.1劣于LlamaGen33.4，不能称双向无损协同。

消融实验：T3a权重αa:αr=1:0→1:1000，零样本75.7→74.3、rFID367.8→35.3；1:10000零样本跌35.4，支持局部折中而非权重任意。T3b从零26.4、MIM74.3、CLIP74.7，预训练重要。T3c第二阶段rFID35.3→3.21但PSNR24.49→23.16；IN1K额外微调2.90非默认。T6倒二层量化前GQA61.2/POPE86.1/MME1398.7，最后层量化前50.7/77.2/1077.7，量化后40.4/50.6/677.17；语义层与量化均影响理解，主LLaVA结果不能代替完全离散UM3理解验证。附T12计数.22低于SD1.5 .35，非各分项最优。

## 6. 局限与疑问（Limitations）

正文post-hoc固定比例与摘要dynamic措辞有差异；loss量级平衡不保证梯度方向冲突消失。强理解主要用量化前连续层，下游分开训练；UM3文字与生成仍有退化。数据4/5/15/16/17/18M及B8曝光预算需作者说明；28bit到UM3词表打包/训练脚本未公开齐全。7blob固定GH提供模型/BSQ/example，HF检查点与卡存在，但无完整原tokenizer、LLaVA/LlamaGen/UM3训练；HF卡CC-BY-NC4与GH Nvidia Source Code License-NC分别记录。未下载权重或复现，不由代码阅读推断原成绩错误。

## 7. 我的思考（Insights）

优势假设（本仓库分析，尚未验证）：在有强预训练初始化、图文大batch可用且任务允许保留连续理解接口时，两阶段训练可能缓解显存约束并取得语义/重建折中；低rFID与高CR适用于静态感知压缩目标。极小字/细笔画、必须全离散理解或严格时序场景可能损失关键细节。需要在同码率、同初始化/预算、相同输入接口下证实优势，不能由较低rFID推出笔顺正确。

可证伪实验（建议方案，尚未运行）：固定初始化/数据/曝光/FLOPs与码率，比较单目标、同权联合、post-hoc固定、在线权重及阶段冻结控制，报告梯度范数/夹角和Pareto曲线；量化前后/各层在同LLM下逐一对齐，补全UM3词表打包，统一/专用模型同预算多seed评价。分别报告细字OCR、有序CER/笔画保真、语言回退和端到端成本；视频需另加事件、抬落笔和可见性真值。方案未执行。

这两项分别回答“在什么任务/分布/指标下有优势”与“如何验证”；上文问题、动机、贡献回答前面三个研究分析问题。
