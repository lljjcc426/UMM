## 2. 现有方法不足（Motivation）

## 3. 核心创新（Contribution）

## 4. 方法流程（Method）

输入与输出：高斯噪声、时间步→图像；训练输入为加噪图像和时间步。

方法框架与模型结构：多尺度U-Net、残差块、GroupNorm、16×16尺度自注意力；T=1000，线性beta由1e-4到0.02。

数据集与分布：CIFAR-10、LSUN等静态图像；各分辨率设置应分别比较。

主要基线：NCSN、GAN及其他似然生成模型；同结构的损失与方差参数化消融更能定位机制。
