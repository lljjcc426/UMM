# 研究判断与修订依据

日期：2026-10-15。事实、推导和待验证假设分开记录；本页不是模型成绩报告。

| 编号 | 当前判断 | 依据与影响 |
|---|---|---|
| D01 | 本仓库为长期工作记录入口 | 用户明确指定；后续资料、分析、方案和实际实验都应回写 |
| D02 | 先研究实际笔顺，再研究效率 | 用户最新重点；效率协议保留，但不替代过程正确性 |
| D03 | UMM不是diffusion的互斥替代物 | 统一任务可以采用扩散／flow生成；比较对象是过程理解如何影响生成 |
| D04 | 读写联合与中文书法统一生成均有先例 | InkSight训练含中文；UniCalli统一列级静态识别与生成；不能主张宽泛首次 |
| D05 | 不能把静态笔顺损失等同实际时间监督 | XMP-Font的LSTM特征约束读取最终字图；同终图错序反例无法靠终态损失区分 |
| D06 | 逐笔／多字生成不是空白 | LVGM、OLHWG、DiffInk提供直接前作；需要在严格执行与UMM归因上证明增量 |
| D07 | 视频文字基准已有手写演化覆盖 | VidScribe含handwriting_stroke；VTR-Bench含文字反馈生成框架；指标仍不等于规范逐笔验证 |
| D08 | 91.2%不代表严格笔顺正确率 | 双域HTR公式(28)为起点、笔画数及总长度均值；保留首笔后交换后续笔可能不改变该分数 |
| D09 | 67.03%不是纯排序率 | 有序实例恢复指标同时要求数量、几何实例匹配及次序；不能当作完美视频裁判 |
| D10 | 规则必须成为强基线和共享条件 | 已知模板的顺序可确定性执行；UMM额外价值应落在实例绑定、状态辨认和实际执行 |
| D11 | 已提交的错误历史不能被未来添墨修复 | 离线回滚可行，但需报告次数／成本；不能把最终正确画面算作全过程正确 |
| D12 | 艺术字体与行草书分设 | 标准笔画结构的风格变换可用指定顺序；连笔减省需要合法变体或专家标注 |
| D13 | 原始材料保存与公开目录分开 | 三项附件对应公开预印本可独立整理；原稿与未公开结果留本地，不因文件名判断录用 |

## 待验证假设

- H1：同终图错序数据使模型真正读取实际事件，而不是背诵规范。
- H2：过程理解的改善能够提升自由生成中的严格整字笔顺成功率。
- H3：在相同输入、数据与预算下，共享训练仍优于分离模块和专门模型。
- H4：在H1–H3相关结果明确后，事件信息可帮助减少采样、理解调用或历史存储成本。

H1成立不自动支持H2；H2成立但H3不成立时，应将贡献表述为过程监督，而非统一架构本身的优势。研究来源与设计细节见[专项分析](../handwriting/05_stroke_order_umm.md)。
