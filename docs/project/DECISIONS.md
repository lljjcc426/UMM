# 研究判断与修订依据

以下记录主要研究判断、证据及待验证假设。

| 编号 | 当前判断 | 依据与影响 |
|---|---|---|
| D02 | 先研究实际笔顺，再研究效率 | 先确认笔顺与执行正确，再比较固定质量目标下的计算成本 |
| D03 | UMM不是diffusion的互斥替代物 | 统一任务可以采用扩散／flow生成；比较对象是过程理解如何影响生成 |
| D04 | 读写联合与中文书法统一生成均有先例 | InkSight训练含中文；UniCalli统一列级静态识别与生成；不能主张宽泛首次 |
| D05 | 不能把静态笔顺损失等同实际时间监督 | XMP-Font的LSTM特征约束读取最终字图；同终图错序反例无法靠终态损失区分 |
| D06 | 逐笔／多字生成不是空白 | LVGM、OLHWG、DiffInk提供直接前作；需要在严格执行与UMM的独立贡献上证明增量 |
| D07 | 视频文字基准已有手写演化覆盖 | VidScribe含handwriting_stroke；VTR-Bench含文字反馈生成框架；指标仍不等于规范逐笔验证 |
| D08 | 91.2%不代表严格笔顺正确率 | 双域HTR公式(28)为起点、笔画数及总长度均值；保留首笔后交换后续笔可能不改变该分数 |
| D09 | 67.03%不是纯排序率 | 有序实例恢复指标同时要求数量、几何实例匹配及次序；不能当作完美视频裁判 |
| D10 | 规则必须成为强基线和共享条件 | 已知模板的顺序可确定性执行；UMM额外价值应落在实例绑定、状态辨认和实际执行 |
| D11 | 已经发生的错误书写过程不能被未来添墨修复 | 离线回滚可行，但需报告次数／成本；不能把最终正确画面算作全过程正确 |
| D12 | 艺术字体与行草书分设 | 标准笔画结构的风格变换可用指定顺序；连笔减省需要合法变体或专家标注 |
| D13 | 探索主线采用过程联合训练＋实际输出反馈 | 方案四定义训练方式，方案二定义生成时的使用流程；H1、H2、H3分层验证，共享收益仍待实验 |
| D14 | 当前笔完成程度属于必要状态 | 半条上横与完整上横需要不同后续动作；仅有笔数或计划进度不能充分决定续写 |
| D15 | 先稳定答案接口和当前线条状态，再加入顺序学习 | 文字状态、实例定位与完成程度错误会混入顺序成绩；用分级门槛定位问题，当前不启动顺序训练 |
| D16 | 完成程度必须有明确参考或目标条件 | 同一当前短线可对应完整短目标或尚未完成的长目标；同当前像素、不同参考的配对检验模型是否真正利用参考 |
| D17 | 简单图像读取、答案格式和参考关系需要分开检验 | Show-o2整幅图小对照存在判断8/8、数量7/8；简洁参考关系格式40/40有效，但存在全答yes，完整匹配10/20，参考对仍失败。格式与基础视觉读取可用不代表当前状态可靠 |
| D18 | 文字状态监督的收益不能替代视觉证据 | 本机文字LoRA在独立文字测试上明显改善内容判断，但同接口的视觉存在成绩从28/52降至19/52，完成配对仍失败；后续需要直接视觉状态监督和文字能力回归 |
| D19 | 总体存在正确率不能掩盖目标缺失错误 | 首轮视觉监督后存在47/52，但未出现仅7/12，多线条中指定目标缺失仅1/6；完成35/52，两问均对17/26。继续分离目标定位与参考比较，暂不启动顺序学习 |
| D20 | 给定正确实例后，完成比较仍有独立错误 | 原模型在12个多线条开发案例上，只保留正确目标后存在24/24、完成19/24；这一外部实例隔离控制不能计为自主定位通过。当前蓝框提示没有改善，不能据此否定所有空间提示 |
| D21 | 增加同图不同目标监督尚未带来稳定状态理解 | 追加500步后，训练子集存在18→21/24、完成13→17/24；原开发集完成35→36/52，两问均对仍17/26，配对改善区间跨零。同图不同状态的目标完成配对仍0/20；后续先检查小训练集拟合与可训练层范围，保持顺序学习未开始 |
| D22 | 固定目标题能拟合，不代表能随问题切换目标 | 最后8层与全部28层均拟合48道已见题，但原开发完成均39/52，同图不同状态的完成配对仍0/20；扩大范围成本约2.7倍，未显示稳定收益。追加检查原适配器已见同图不同目标题，完成配对0/84（6组），优先解决训练内目标对应，并保留参考关系对照 |
| D23 | 集中训练的逐题收益不能掩盖目标混淆和能力退化 | 同图不同目标题继续648步后，训练完成配对0→11/84、开发0→1/20，仍未稳定；原开发完成36→44/52，但仅当前完成44→12/50，文字95→91/96。新权重不替代基线，后续检验目标位置监督并保留文字／仅当前复习；同权重前向梯度路径对照112题答案不变，未解释本批目标错误 |
| D24 | 训练后的参考位置辅助有效，自主目标对应仍需单独解决 | 匹配训练中，有框输入的目标完成配对0→18/20；加框模型移除框后仅1/20。两组文字94/96、仅当前46/50，未复现严重退化。目标框来自已知参考且包含完整范围，开发仅3组／一个种子；下一步分离参考定位与状态读取，不据辅助成绩启动顺序学习 |
| D25 | 坐标误差降低不足以说明学会定位 | 明确位置监督1194步后，已见定位4/84、开发0/28；真实图误差55.06像素，优于空白图71.52，但差于训练坐标中位数34.41。辅助状态配对仍18/20，文字完成94→92/96。先诊断冻结视觉表示与空间输出，不继续按同一配置追加训练或启动顺序学习 |
| D26 | 视觉空间信息可读，目标掩码泛化仍需改善 | 冻结UMM线性网格读出开发IoU92.1%，位置先验16.7%；新增问题条件空间头完整批次拟合后训练定位82/84、开发13/28，同图换问题0/28。全部预测格合并仅3/28，正确网格上界28/28。优先改进目标监督和掩码连续性，不能把读出头成绩当作原语言坐标输出或H1通过 |
| D27 | 扩展监督与笔迹过滤改善定位，仍需检验实际状态用途 | 新开发48组／112目标上，旧头14/112，扩展训练64/112；与已有笔迹预测取交集后88/112。111/112掩码更接近正确目标，但范围仍有误差。训练暴露次数增加、交集为追加诊断，不能归为单因素或独立验收 |
| D28 | 定位误差达标不能替代完成程度判断 | 预测框下存在56/56、完成42/56、目标完成配对14/20；无框1/20、正确框18/20。14道完成错误的位置全部满足12像素容差，正确框下原本答对的10题变错。先固定黑色笔迹检验提示框边界／宽度敏感性，再改进状态监督与新几何验证；不进入顺序学习 |
| D29 | 提示框的小幅变化能改变实际状态答案 | 固定黑色笔迹和模型，8种±6像素变化共896题；框下移使完成52→42/56，含原框全部条件均正确仅36/56。框仍指向同一目标，不能用格式成功或定位容差替代状态稳定性 |
| D30 | 扰动监督的局部收益不足以替换状态基线 | 两组同样256题／64步，扰动组预测框完成47/56、准确框复习45/56，差异区间跨零；准确框下48/56与51/56，且两组无参考存在47→44/50。保留原基线，检验UMM目标区域的直接特征比较和新状态几何；新适配器与旧定位头兼容性未测，不宣称端到端通过 |
| D31 | 区域状态读出能够利用画面，接近完成的边界仍需监督 | 新增状态头在正确区域下完成290/317、预测区域258/317，无参考25/25；同当前不同参考配对6/6。85%进度仅33/56和16/56，训练部分进度只有25%／60%；当前特征置空后全部答未出现。下一步同预算检验进度覆盖，并分开位置误差与状态边界；新增头成绩不代替原语言能力、顺序理解或统一学习收益 |
| D32 | 进度覆盖能减少提前判断完整，但仍需检验反向错误与细小缺口 | 相同509例／400步，预测区域完成322→370/441，90%进度12→52/56；97%仅17/56，完整57→46/62。同一头换正确区域完整60/62，最大连通筛选则完整57/62但总体358/441。保留全部退化，不用总分或筛选替代稳定性；下一步做其他笔迹相同的末端缺口配对 |
| D33 | 完成状态需要同时检验末端辨别与背景稳定性 | 固定其他笔迹，预测区域完整／缺1像素配对1/56、缺16像素22/56；同一头用正确区域后16像素37/56。1像素部分题28/56中27例的完整成员也答部分。只改变其他线条使完整答案改变19/56；正确区域仍有背景影响。8–16像素分数通常朝正确方向变化，不能认定信息已全部丢失；下一步分开目标与背景配对监督，继续保留完整反向错误及同预算对照 |

DiffInk的代码核查还需区分VAE阶段的识别与风格监督、DiT阶段实际反向传播的损失，以及仅用于日志的指标。日志中出现某指标，不代表该指标参与训练；详见[DiffInk分析](../handwriting/papers/diffink.md)。

## 待验证假设

- H1：模型能够区分同终图不同历史，恢复实际实例顺序、首错和当前笔完成程度。
- H2：过程理解的改善能够提升自由生成中的严格整字笔顺成功率。
- H3：在相同输入、数据与预算下，共享训练仍优于分离模块和专门模型。
- H4：在H1–H3相关结果明确后，事件信息可帮助减少采样、理解调用或历史存储成本。

H1成立不自动支持H2；H2成立但H3不成立时，应将贡献表述为过程监督，而非统一架构本身的优势。研究来源与设计细节见[专项分析](../handwriting/05_stroke_order_umm.md)。

当前六方案的分工、首阶段范围和推进条件统一见[主线定义](MAINLINE.md)。
