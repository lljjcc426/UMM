与[五项基础实验](../experiments/minimum_experiments.md)的对应：SO-01对应原E3，SO-02对应原E4；原E1的表示诊断可作为SO-01前置分析；原E2、E5保留在EF-01中。

SO-02用于拆分执行瓶颈，SO-02B直接检验H2，两者的结果单列。SO-01先用“三”的上→中→下与上→下→中检查流程，再扩展结构类型；通过最小案例后，仍需在留出字形和风格上评价。后续生成同时测试完整前缀和当前笔未完成的前缀。

运行后必须记录：日期、模型／代码版本、输入信息、数据划分、实际命令或配置、硬件、全部尝试数、失败状态、指标定义及结果文件。已有模板为[experiment_template.csv](../../data/experiment_template.csv)。

不得把规则检查、文件结构测试或玩具事件指标的结果填为模型成绩。
