### 每项任务执行前

Codex 先询问用户本次希望验收的内容、允许的资源/下载/成本与约束，得到明确授权后自行完成技术实现。任务结束后汇报日志、完整数据、失败和待决事项，再征询下一任务。

### 阶段验收

完整 P0 通过之前，不提交面向 main 的合并 PR。准备验收时将 [阶段发布清单](P0-release.json) 的状态、实验路径、审批引用更新并运行阶段合并门禁。完整规则见 [分支制度](../BRANCH_WORKFLOW.md)。

允许在阶段分支保留无效或有缺陷的尝试，禁止将它们当作已验收结果合入主线。
