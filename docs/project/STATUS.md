# 研究进展

## 当前阶段：先验证答案接口与当前线条状态

工作标题：**实际笔顺理解驱动的统一多模态中文书写视频生成**。

当前主线为方案四＋方案二：联合训练过程理解与生成，生成时观察实际结果再续写。首阶段采用单字、固定视角、无手部遮挡、清楚笔画及保留基本结构的风格变化。

工作分支：`research/stroke-order-joint-feedback`。后续本主线的数据、实验和文献更新集中在该分支，待办与阶段结果通过[总跟踪Issue #1](https://github.com/lljjcc426/UMM/issues/1)跟进。六个方案的分工及研究范围见[主线定义](MAINLINE.md)。

| 研究假设 | 当前状态 | 下一项证据 |
|---|---|---|
| H1：理解实际笔顺与进度 | 位置辅助下状态判断改善，自主目标对应仍未通过 | 先预测参考目标位置，拆分定位与状态错误，再独立验收 |
| H2：理解帮助自由生成 | 待验证；尚无模型生成实验 | 联合训练与实际反馈的分别消融、整字自由滚动 |
| H3：统一学习有额外价值 | 待验证；尚无联合/分离对照 | 可比数据、输入和计算预算下的独立对照 |

## 实验顺序

1. H1／SO-01：实际笔顺、首错及当前笔完成程度的理解诊断。
2. H2／SO-02、SO-02B：先诊断正确控制的执行，再验证联合训练与实际反馈是否改善自由生成。
3. H3／SO-03：相同数据、输入与可比预算下的联合、分离和专门模型对照。
4. SO-04：多字与风格泛化。
5. EF-01：过程信息在少步生成和缓存压缩中的保持。

详细设计见[实验计划](EXPERIMENTS.md)与[笔顺专项](../handwriting/05_stroke_order_umm.md)。
