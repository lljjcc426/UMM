# 研究进展

## 当前阶段：先验证答案接口与当前线条状态

工作标题：**实际笔顺理解驱动的统一多模态中文书写视频生成**。

当前主线为方案四＋方案二：联合训练过程理解与生成，生成时观察实际结果再续写。首阶段采用单字、固定视角、无手部遮挡、清楚笔画及保留基本结构的风格变化。

工作分支：`research/stroke-order-joint-feedback`。后续本主线的数据、实验和文献更新集中在该分支，待办与阶段结果通过[总跟踪Issue #1](https://github.com/lljjcc426/UMM/issues/1)跟进。六个方案的分工及研究范围见[主线定义](MAINLINE.md)。

| 研究假设 | 当前状态 | 下一项证据 |
|---|---|---|
| H1：理解实际笔顺与进度 | 两种适配范围均能拟合小训练集，目标切换仍不稳定 | 检查同图不同目标训练内学习，修订监督与训练安排，再独立验收 |
| H2：理解帮助自由生成 | 待验证；尚无模型生成实验 | 联合训练与实际反馈的分别消融、整字自由滚动 |
| H3：统一学习有额外价值 | 待验证；尚无联合/分离对照 | 可比数据、输入和计算预算下的独立对照 |

## 最近结果：2026-10-16

本机已完成小训练集拟合与适配范围对照。固定12个已见多线条案例、3个几何组、48题，最后8层与全部28层q/v LoRA从同一适配器继续，各训练12轮、144步。完整Show-o2 UMM和冻结视觉编码器保留，只评价最终权重。

| 指标 | 初始适配器 | 最后8层拟合 | 全部28层拟合 |
|---|---:|---:|---:|
| 已见训练题：存在正确 | 21/24 | 24/24 | 24/24 |
| 已见训练题：完成正确 | 17/24 | 24/24 | 24/24 |
| 原开发：存在正确 | 47/52 | 48/52 | 49/52 |
| 原开发：完成正确 | 36/52 | 39/52 | 39/52 |
| 原开发：完成两问均对 | 17/26 | 18/26 | 19/26 |
| 同图不同状态目标对：完成都答对 | 0/20 | 0/20 | 0/20 |

- 两配置都能拟合48道固定目标题，因此这组失败不能直接归为最后8层适配能力不足。训练集每组只询问原指定目标，仍可能包含记忆，不能证明随问题切换目标。
- 原开发集26案例、7个几何组。两配置的完整类别均仅5/14，同当前不同参考的唯一配对均失败。全部28层相对最后8层的存在、完成逐题改善区间分别为[-3.8,9.1]、[-5.4,5.4]个百分点，未显示稳定收益。
- 全部28层与最后8层梯度训练分别18.4、6.9分钟；样本和更新次数相同，参数量及成本不同。不存在相同计算预算下的额外收益结论。
- 初始小批次损失差异已做数值核查：4道训练题的初始推理分数、答案完全一致；让梯度同样经过早期冻结层后，训练分数也一致。该差异与当前MPS／bfloat16的梯度计算路径有关，不能将本轮当作纯粹层数变化的严格因果证据。
- 本轮尚未评价两份拟合权重的文字能力保持；原文字测试成绩属于旧权重。原130个视觉留出案例仍未运行。

**两项前置门槛仍未通过。** 上一轮适配器的全部同图不同目标训练内评价已完成：存在175/216、完成138/216，两目标完成配对0/84（6组，含两种问法）。目标切换在训练内就未学稳，下一步优先改善这项拟合，再检查开发迁移；不因固定目标题全对而启动顺序学习。完整训练、逐题预测、配对统计及数值核查见[最新拟合诊断](../../results/h1/showo2_video_1_5b/fit_scope_v1/README.md)，此前结果见[目标控制与追加监督](../../results/h1/showo2_video_1_5b/target_controls_v1/README.md)。

此前Janus-Pro-1B原排列及移位后的严格评分4/33、6/33，两轮均29次以A开头；图像级UMM短序列诊断保留在[历史报告](../experiments/h1_umm_diagnostic.md)。当前不据这些诊断推断H1成立。

## 实验顺序

1. H1／SO-01：实际笔顺、首错及当前笔完成程度的理解诊断。
2. H2／SO-02、SO-02B：先诊断正确控制的执行，再验证联合训练与实际反馈是否改善自由生成。
3. H3／SO-03：相同数据、输入与可比预算下的联合、分离和专门模型对照。
4. SO-04：多字与风格泛化。
5. EF-01：过程信息在少步生成和缓存压缩中的保持。

详细设计见[实验计划](EXPERIMENTS.md)与[笔顺专项](../handwriting/05_stroke_order_umm.md)。
