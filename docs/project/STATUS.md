# 研究进展

## 当前阶段：先验证答案接口与当前线条状态

工作标题：**实际笔顺理解驱动的统一多模态中文书写视频生成**。

当前主线为方案四＋方案二：联合训练过程理解与生成，生成时观察实际结果再续写。首阶段采用单字、固定视角、无手部遮挡、清楚笔画及保留基本结构的风格变化。

工作分支：`research/stroke-order-joint-feedback`。后续本主线的数据、实验和文献更新集中在该分支，待办与阶段结果通过[总跟踪Issue #1](https://github.com/lljjcc426/UMM/issues/1)跟进。六个方案的分工及研究范围见[主线定义](MAINLINE.md)。

| 研究假设 | 当前状态 | 下一项证据 |
|---|---|---|
| H1：理解实际笔顺与进度 | 已完成文字、视觉及同图不同目标LoRA；本次追加训练未稳定改善 | 先做小训练集拟合与更新范围对照，稳定两项门槛后再加入顺序学习 |
| H2：理解帮助自由生成 | 待验证；尚无模型生成实验 | 联合训练与实际反馈的分别消融、整字自由滚动 |
| H3：统一学习有额外价值 | 待验证；尚无联合/分离对照 | 可比数据、输入和计算预算下的独立对照 |

## 最近结果：2026-10-16

Show-o2-1.5B-w-video-und完整检查点已完成目标对应控制和第二轮视觉监督。新增48幅画面、6个几何组，同图询问不同目标，得到864条新题；加624条原视觉题和512条原文字题，共2000条。保持最后8层q/v LoRA，继续1轮、500步。本机图像编码约12.6分钟，梯度训练约18.9分钟，只评价最终权重。

- 定位控制使用追加训练前的固定模型：仅保留已知正确目标时，存在19→24/24、完成13→19/24。隔离依赖外部实例标注，不能作为自主定位证据；完成仍有错误。未训练过的蓝框标记未改善这一小对照。
- 在12个见过的训练案例上，追加监督后存在18→21/24、完成13→17/24；仍未稳定拟合。不能把开发失败全部归为新几何泛化。

- 原文字适配的独立测试完成两问均对94.9%，该成绩属于旧权重。新模型未做新的独立验收；原130个视觉留出案例仍未运行。

**目标对应和完成比较都尚未稳定，两项前置门槛仍未全部通过。** 先用少量已见样本比较训练内拟合及可训练层范围，区分是否需要改变适配方式；不继续无差别增加同类题，也不提前进入顺序学习。该对照尚未实施，现有结果不能唯一判定失败原因。完整原始回答、配对统计及训练设置见[目标控制与追加监督结果](../../results/h1/showo2_video_1_5b/target_controls_v1/README.md)；历史结果见[Show-o2报告](../../results/h1/showo2_video_1_5b/README.md)。

此前Janus-Pro-1B原排列及移位后的严格评分4/33、6/33，两轮均29次以A开头；图像级UMM短序列诊断保留在[历史报告](../experiments/h1_umm_diagnostic.md)。当前不据这些诊断推断H1成立。

## 实验顺序

1. H1／SO-01：实际笔顺、首错及当前笔完成程度的理解诊断。
2. H2／SO-02、SO-02B：先诊断正确控制的执行，再验证联合训练与实际反馈是否改善自由生成。
3. H3／SO-03：相同数据、输入与可比预算下的联合、分离和专门模型对照。
4. SO-04：多字与风格泛化。
5. EF-01：过程信息在少步生成和缓存压缩中的保持。

详细设计见[实验计划](EXPERIMENTS.md)与[笔顺专项](../handwriting/05_stroke_order_umm.md)。
