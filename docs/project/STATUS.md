# 研究进展

## 当前阶段：先验证答案接口与当前线条状态

工作标题：**实际笔顺理解驱动的统一多模态中文书写视频生成**。

当前主线为方案四＋方案二：联合训练过程理解与生成，生成时观察实际结果再续写。首阶段采用单字、固定视角、无手部遮挡、清楚笔画及保留基本结构的风格变化。

工作分支：`research/stroke-order-joint-feedback`。后续本主线的数据、实验和文献更新集中在该分支，待办与阶段结果通过[总跟踪Issue #1](https://github.com/lljjcc426/UMM/issues/1)跟进。六个方案的分工及研究范围见[主线定义](MAINLINE.md)。

| 研究假设 | 当前状态 | 下一项证据 |
|---|---|---|
| H1：理解实际笔顺与进度 | 集中训练有部分收益，目标切换仍不稳定且缺少参考能力退化 | 检验目标位置监督与能力保持，再独立验收 |
| H2：理解帮助自由生成 | 待验证；尚无模型生成实验 | 联合训练与实际反馈的分别消融、整字自由滚动 |
| H3：统一学习有额外价值 | 待验证；尚无联合/分离对照 | 可比数据、输入和计算预算下的独立对照 |

两组均从原目标对比适配器开始，使用432道参考＋当前目标状态题、312道仅当前题和512道文字题，各3轮／942步。模型、数据顺序、提示与预算相同；蓝框组额外获得来自完整参考的目标位置，无框组保留原图。仅当前题不加框，避免泄露未提供的完整长度。

## 最近完成的结果：2026-10-16

本机已完成同图不同目标的集中训练：从原目标对比适配器继续，固定432道参考＋当前训练题、48幅图、108个目标案例、6个几何组，训练6轮／648步。只更新最后8层q/v LoRA的311,296个参数；完整Show-o2 UMM保留，不新增图像，不混入旧任务，只评价最终权重。图像编码2.5分钟、梯度训练29.9分钟。

|---|---:|---:|

| 已见训练：不同目标完成配对 | 0/84 | 11/84 |

| 准确文字开发：存在／完成正确（去重） | 96/96、95/96 | 93/96、91/96 |

**两项前置门槛仍未通过，本轮权重不替代原基线。** 原开发完成逐题与两问均对均84.6%，低于85%；存在两问均对88.5%，低于90%。完整类别8/14，同当前不同参考的唯一配对两种问法均失败。

- 训练完成配对有所改善，但仍仅11/84。开发配对含两种问法、只有3个几何组；1/20不能证明稳定目标对应。真值不同却给相同完成答案的目标对，训练仍69/84、开发18/20。
- 仅当前条件下，所有完成答案变成“未出现”；去重后应答“未知”的38题全部错误，完成下降64个百分点，7组配对95%区间[-73.7,-53.6]。本轮未训练未知类别，但没有等预算混合复习对照，不能唯一归因。
- 原参考＋当前开发的完成改善区间为[0.0,30.4]个百分点，只有7组。文字完成下降的13组区间为[-10.0,0.0]。单种子、小量合成图不能代表未见汉字和字体。
- 对此前观察到的MPS／bfloat16梯度路径差异，补做同权重112题前向对照：保持LoRA autograd，不反向、不更新。答案全部与普通推理一致，目标完成配对仍1/20，未改善本批错误。
- 原130例视觉留出集仍未运行，旧权重的独立文字测试成绩不赋给本轮权重。顺序学习、H2/H3未开始。

完整训练、逐题回答、配对统计、固定示例及退化分析见[最新集中状态学习](../../results/h1/showo2_video_1_5b/target_focus_v1/README.md)。此前[适配范围诊断](../../results/h1/showo2_video_1_5b/fit_scope_v1/README.md)中，最后8层和全部28层都能拟合48道固定目标题，开发完成均39/52、目标完成配对均0/20；扩大层数未显示稳定收益。所有历史记录保留。

此前Janus-Pro-1B原排列及移位后的严格评分4/33、6/33，两轮均29次以A开头；图像级UMM短序列诊断保留在[历史报告](../experiments/h1_umm_diagnostic.md)。当前不据这些诊断推断H1成立。

## 实验顺序

1. H1／SO-01：实际笔顺、首错及当前笔完成程度的理解诊断。
2. H2／SO-02、SO-02B：先诊断正确控制的执行，再验证联合训练与实际反馈是否改善自由生成。
3. H3／SO-03：相同数据、输入与可比预算下的联合、分离和专门模型对照。
4. SO-04：多字与风格泛化。
5. EF-01：过程信息在少步生成和缓存压缩中的保持。

详细设计见[实验计划](EXPERIMENTS.md)与[笔顺专项](../handwriting/05_stroke_order_umm.md)。
