# 研究进展

## 当前阶段：先验证答案接口与当前线条状态

工作标题：**实际笔顺理解驱动的统一多模态中文书写视频生成**。

当前主线为方案四＋方案二：联合训练过程理解与生成，生成时观察实际结果再续写。首阶段采用单字、固定视角、无手部遮挡、清楚笔画及保留基本结构的风格变化。

工作分支：`research/stroke-order-joint-feedback`。后续本主线的数据、实验和文献更新集中在该分支，待办与阶段结果通过[总跟踪Issue #1](https://github.com/lljjcc426/UMM/issues/1)跟进。六个方案的分工及研究范围见[主线定义](MAINLINE.md)。

| 研究假设 | 当前状态 | 下一项证据 |
|---|---|---|
| H1：理解实际笔顺与进度 | 已完成文字与首轮视觉LoRA；目标缺失与完成判断仍不可靠 | 分离目标定位与参考对应，稳定两项门槛后再加入顺序学习 |
| H2：理解帮助自由生成 | 待验证；尚无模型生成实验 | 联合训练与实际反馈的分别消融、整字自由滚动 |
| H3：统一学习有额外价值 | 待验证；尚无联合/分离对照 | 可比数据、输入和计算预算下的独立对照 |

## 最近结果：2026-10-16

Show-o2-1.5B-w-video-und完整检查点已完成首轮直接视觉状态适配：78个新视觉案例、624条视觉题与512条原文字训练题混合训练2轮。只更新31万个LoRA参数，图像编码约8分钟，梯度训练约18分钟，均在M5／16GB本机完成。

- 参考＋当前开发评价：存在47/52（90.4%）、完成35/52（67.3%）；相同答案约束下冻结模型为28/52、13/52，原文字适配为19/52、15/52。
- 等价问法稳定性：存在两问均对23/26（88.5%）、完成17/26（65.4%），仍未达到门槛。只有7个开发几何组，尚无独立视觉泛化结论。
- 主要错误：目标已出现的存在题40/40正确，未出现只对7/12；多线条中指定目标缺失的6题只对1题。完成题中“完整”7/14、“未出现”4/12，仍有明显类别偏差。
- 参考关系：唯一一组同当前、不同参考的开发配对，两种问法均答对；样本量不足以认定参考对应已经稳定。
- 仅当前画面：去除相同问题、相同图像的重复项后，存在45/50、完成44/50；确实缺少完成依据时38/38回答未知，目标缺失仍有错误。
- 文字能力回归：去重后的原文字开发集存在96/96、完成95/96，与视觉训练前相同。原文字适配的独立测试完成两问均对94.9%；该分数属于原权重，不能直接作为新权重的独立结果。

**本机小规模视觉监督已实际跑通，并改善了当前开发表现；两项前置门槛仍未全部通过。** 后续先定位目标选择与参考比较的失败，再决定训练修订。原130个视觉留出案例尚未运行，顺序学习保持未开始。完整原始回答、配对置信区间与失败分析见[本轮结果](../../results/h1/showo2_video_1_5b/README.md)。

此前Janus-Pro-1B原排列及移位后的严格评分4/33、6/33，两轮均29次以A开头；图像级UMM短序列诊断保留在[历史报告](../experiments/h1_umm_diagnostic.md)。当前不据这些诊断推断H1成立。

## 实验顺序

1. H1／SO-01：实际笔顺、首错及当前笔完成程度的理解诊断。
2. H2／SO-02、SO-02B：先诊断正确控制的执行，再验证联合训练与实际反馈是否改善自由生成。
3. H3／SO-03：相同数据、输入与可比预算下的联合、分离和专门模型对照。
4. SO-04：多字与风格泛化。
5. EF-01：过程信息在少步生成和缓存压缩中的保持。

详细设计见[实验计划](EXPERIMENTS.md)与[笔顺专项](../handwriting/05_stroke_order_umm.md)。
