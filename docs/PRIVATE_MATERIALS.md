# 原始附件与公开研究记录

该GitHub仓库为公开仓库。本地 `research/` 保存原始研究材料、论文缓存、附件精读和截图，已被Git忽略。用户原始文件未删除。

四份附件的原稿及本地提取文本不直接上传。已核对三项公开预印本：Timage（2606.19944）、BoxTuning（2604.11136）和ORVOS（2604.11411）；仓库依据公开版本整理独立分析，见 [公开预印本笔记](evidence/public_preprint_reviews.md)。不公开匿名原稿与作者身份之间的推断，不据文件名或预印本评论认定录用。

其余未找到公开对应材料的稿件继续只保留私有状态，原文、截图和未公开结果留在本地。网页版历史四项占位保留其原编号，当前处理状态见 `data/withheld_private_records.json`。

公开版本将私有细节替换为明确说明或公开入口，相关变化登记在整合记录及文件对应表中；不将删去内容伪装为已经公开归档。字体、模型权重、受限数据和论文全文不随库分发。
