# 提示框扰动的小规模匹配训练

从已有训练数据抽取32个参考＋当前目标案例、16个仅当前案例和16个文字案例，每个案例保留两种问法及存在／完成两项任务。每组共256题，其中参考128题、仅当前64题、文字64题。参考案例覆盖6个训练几何组，按布局及完成类别分层；复习案例按完成类别分层。开发问题不进入训练。

`exact/`使用准确参考框，`jitter/`使用±6像素的位置或尺寸扰动。两组的样本、标签、顺序和训练设置相同。扰动按完整参考几何与目标名称分配：同一参考目标在所有当前状态中使用同一种变化，不能由当前进度决定框。所有黑色笔迹保留。`cue_assignment.json`保存12个参考目标的扰动分配，`selection.json`保存抽样编号与类别计数。

`text_replay/`由两组共享；仅当前输入不加框。参考完成题类别为未出现24、部分20、完整20；仅当前为未知16、未出现16；文字为部分12、完整10、未出现10。数字为问题数，两种问法不算独立案例。

`evaluation/`复用扰动诊断中预先指定的`x_plus6`与`width_plus6`，它们在读取该诊断评分前固定。冻结模型的评分随后显示`y_plus6`下降最大，因此在训练前追加这项压力检验，单独标为探索性补充。三项不能代表八种变化全部已检验。正确框、预测框、文字与仅当前开发对照复用已有输入。

完整训练设置及结果见[实验记录](../../../results/h1/showo2_video_1_5b/cue_robustness_pilot_v1/README.md)。脚本为`python scripts/h1_cue_robustness_pilot.py build`。新增数据不改写旧训练集，原130例视觉测试继续留出。
