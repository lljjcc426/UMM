# 目标区域状态数据

此批数据用于检查UMM的空间特征能否支持存在与完成判断，不包含顺序或视频生成。完整参考与当前画面分别保存在432×432图像上半部，位置、比例一致，输入不绘制蓝框，不裁剪或移除其他线条。

训练包含48组平行横线、平行竖线与交叉几何，12组同当前不同参考控制，以及12组无参考单目标控制；开发分别24、6、6组。几何种子10430／10431，所有目标与进度变体按整组划分。训练比例为0、0.25、0.6、1；开发为0、0.15、0.45、0.85、1。同图中不同目标的完成状态错开，检查能否随问题切换目标。

原始训练520例、开发322例。无参考空白画面跨名义几何重复，训练与评分按实际RGB输入在各集合内去重，保留509／317例；原始记录不删除。唯一空白控制也出现在训练和开发中，因此不作为未见几何证据。无参考非空图没有完整目标长度或隐藏参考；此条件使用固定上半部区域，不使用完整目标掩码。

- `images.json`列出实际图像；`cases.json`记录状态与分组标签。
- `queries.json`记录仅由完整参考与目标名称组成的定位输入；其中几何字段用于生成训练标注及评分，不进入定位模型。
- 正确目标掩码作为位置辅助条件；预测掩码来自既有冻结UMM、问题条件空间头与笔迹头。两种位置来源分别报告。
- `language_baseline/`在定位完成后生成，用相同开发状态比较既有语言回答。参考和当前上下拼接，画预测框，保留原提示与固定答案接口。

完整设置见[实验计划](../../../results/h1/showo2_video_1_5b/region_state_v1/plan.json)。本批属于新状态几何开发实验；未使用原130例视觉独立测试，不提供汉字、字体或时序泛化结论。
