# UMM本体的H1首轮诊断

此版本用于Janus-Pro-1B的理解路径，2026-10-16固定于首次推理之前。保留[pilot_v1](../pilot_v1/README.md)的原始规则绘图，重新拆分问题、选取事件帧，降低上下文与输出负担。此前Qwen3-VL实验仅作为外部辅助对照，不能替代本版本的UMM测试。

## 输入与问题

| 条件 | 数量 | 图片与评价对象 |
|---|---:|---|
| `seen_mc` | 8 | 单张当前图；选择实际可见线条，部分出现也算可见 |
| `completion_mc` | 6 | 完整参考＋当前图；区分完整、部分和未出现 |
| `order_mc` | 4 | 空白＋每笔结束时的累积画面；恢复首次出现顺序 |
| `first_error_mc` | 4 | 同上；相对给定顺序定位第一次换序错误 |
| `direction_mc` | 2 | 上横25%与50%进度的相邻帧；区分左→右和右→左 |
| `early_switch_mc` | 2 | 完整参考＋换笔前后帧；判断上一笔是否完成 |
| `oracle_action_mc` | 5 | 准确文字状态；选择继续当前笔、开始下一笔、结束或停止处理错误 |
| `static_unknown_mc` | 2 | 只有最终图；选择实际顺序不可确定 |

共33个输入，每题四个选项，只回答A/B/C/D。正确选项按输入序号轮换，分布A=9、B=8、C=8、D=8；干扰选项以固定随机种子排列。独立均匀猜测的期望为25%，始终选A为9/33；小样本不适合仅凭略高于25%就认定理解成立。

每次独立输入，不包含其他题的回答。选项比自由回答提供了额外信息，因此不能和此前Qwen3-VL的复杂JSON任务直接比较模型高低。全部病例来自受控直线绘图，没有训练或留出泛化集。

## 过程信息与边界

最多4张图片、每张按模型处理为384×384及576个图像token，实际总长度由推理脚本记录并限制在官方4096上下文以内。

顺序题保留空白及每笔完成时的状态，足以读取笔画首次出现先后；这些帧不用于评价笔内方向。方向题另外使用相邻增长帧。提前换笔题包含完整参考和实际换笔前后状态，保留半笔证据。每类问题只评价输入中可观察的属性。

动作题提供准确文字状态，隔离视觉读取与决策；它不能证明模型能够从自己生成的视频恢复状态。当前动作策略遇到已确认错误即停止，不评价修补或自由生成。

Janus-Pro为图像级UMM，官方处理器及模型接口可接受多张图片，当前用此接口承载短帧序列。这不等于已验证原生视频理解或视频生成能力。H1只检查UMM本体的理解端，H2、H3另行验证。

## 评分与复现

`inputs.jsonl`保存图片、提示和选项；`labels.jsonl`保存正确选项及其语义。运行脚本不读标签。仅接受单个选项字母，可带句号或空白；多选、解释、其他格式均计错，原文完整保留。输出没有修补或重试。

```bash
python scripts/h1_umm_dataset.py
python scripts/h1_run_janus.py --output results/h1/janus_pro_1b/new_run
python scripts/h1_score.py results/h1/janus_pro_1b/new_run/predictions.jsonl --dataset data/h1/umm_pilot_v1
```

环境和模型准备见[UMM H1报告](../../../docs/experiments/h1_umm_diagnostic.md)。本版本运行后不修改提示、选项或标签，后续实验使用新版本。
