# 扩展几何的目标定位数据

固定144个训练几何组、48个开发几何组，共336个训练目标、112个开发目标。每张432×432图的上半部为完整线条参考，下半部空白。同一图中的全部目标问题留在同一集合。

包含三条平行横线、两条平行竖线和一横一竖交叉。相较之前的位置诊断，横线分别改变起点与长度，竖线分别改变上下端点，交叉位置可以偏离中心；线宽从3、5、7、9像素中采样。横线相邻间隔至少24像素，两竖线相隔至少40像素。训练和开发分别使用固定种子10421、10422，仍为相同渲染方式和目标词下的几何迁移。

模型只接收参考图及目标名称对应的问题；不接收正确框、目标网格、当前书写状态、完成比例或坐标。`cases.json`中的完整路径边界和线宽用于训练监督与评分；`images.json`用于图像编码；实验目录的`inputs.json`保存实际问题，不含坐标标签。

目标标签由对应线条单独渲染得到：27×27网格，每格16×16像素，至少8个黑色像素记为前景。所有训练／开发目标的正确网格都能在既定最大四连通部分换算下达到四边界12像素容差；这项检查仅说明标注离散化可用，不是模型成绩。

构建脚本为`python scripts/h1_target_grid_generalization.py build`。构建会创建新目录，已有数据不覆盖。完整训练设置见[plan.json](plan.json)，运行与结果见[实验记录](../../../results/h1/showo2_video_1_5b/target_grid_generalization_v1/README.md)。本批不包含未见汉字、字体风格或时序任务，原130例视觉留出测试保持未用。
