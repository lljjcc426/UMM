# T4固定D0机制数据

20个底层坐标轨迹组，训练10／开发5／测试5；每组6种过程，共120段视频。所有采样前缀、换序、反向、半笔、提前换笔、合并事件版本都随同一轨迹组划分。cases.json引用原probe的五组几何只用于训练，另外15组在运行前独立抽样坐标，均为原创数据。脚本：scripts/h1_event_study.py，seed20261018。

这是已见基本结构内的几何变化测试：各划分都有三、十、竖平行、折和斜交叉。单一渲染器、线宽13、黑白画面；没有未见字体或独立汉字类别。五个测试同终态配对远少于正式建议100组，不能作为H1最终验收。原130视觉留出保持未用。

查询给规范ID、类型和由参考模板导出的四分之一画布粗中心提示；主系统不读取精确实例mask或实际事件日志。这是带粗位置条件的实例绑定，完全不提供空间提示的情况尚未验证。正确mask只用于监督、评分、oracle条件。画面无笔尖，几何完整不能证明抬笔。B的消失分支在本批仅有负例，未验证历史涂改的检出能力。

复现顺序：先build固定数据，再extract冻结特征，再h1_event_experiment.py运行全部预注册小头。权重及特征只保留本地checkpoints；仓库保存源图、视频、标注、配置和完整评价。
