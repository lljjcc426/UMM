# T7独立实例与起笔数据

原创D0合成几何，允许本项目复用。40训练、20开发、30测试组，五结构族×三笔/五笔；全部405段及9720个观察随底层几何分组。完整配置见[协议](../../../docs/experiments/h1_t7_protocol.md)。

每组包含完整参考、93帧无损RGB视频与24幅实际抽样PNG。正常与可见换序同终态、最近4/8帧相同；mergedA/B全部实际输入相同但源顺序不同。实际笔顺只按可见帧标注，隐藏源历史不可恢复时保留未知与部分关系。

`cases.json`含指定任务查询与评分标签，`event_logs.json`仅用于标签/oracle。正式输入白名单排除路径、变体、划分、标签、源顺序和真实区域。交叉共享像素允许多实例归属；独有像素仅用于测量可见事件。无真实字、艺术风格、手部、遮挡或自然视频泛化证据。
