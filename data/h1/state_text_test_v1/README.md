# 固定文字状态模型的留出验证

本集合用于验证已经固定的`h1_text_state_lora_v1`适配权重与固定答案解码接口。仅包含准确文字状态下的存在和完成程度问题；不评价视觉、实际顺序、动作或汉字风格泛化。

在查看本集合的模型输出前，固定生成规则：种子40519，各形状家族生成8个几何组，状态为0、35%、75%和完整，另有同当前长度不同参考的控制。增加0.8–1.2的纵向缩放，使竖线长度也变化。排除与`state_training_v1`训练或开发问题完全重合的整组样本；该排除只读取问题文本，不依据模型预测或正确率。

最终为196个几何案例、784题，其中704个不同问题文本、46个按可见文字归并的组。报告全部尝试，并另外报告重复问题仅计一次的成绩及配对置信区间。同一形状家族和指令模板仍在训练中出现，本集合只检验未见长度记录与组合。

冻结模型与训练模型使用相同固定答案解码。模型、接口、训练步数和评价规则在本轮测试前固定；如果后续据此修改文字训练或接口，该集合转为已使用的开发证据，新的最终评价需要另行留出。

重建：`python scripts/h1_state_gate.py build-text-test`。`build.json`保存排除组及生成条件，`cases.json`保存参数，`inputs.jsonl`为输入，`labels.jsonl`仅用于评分。

本集合与原`state_gate_v1`的130个视觉留出案例分开；后者仍未运行。
