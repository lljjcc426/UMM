# 目标末端缺口配对

用于检验完成程度的细节读取。复用上一轮进度覆盖开发集的24组几何、56个目标，每个目标构造0、1、2、4、8、16像素六种末端缺口，共336个当前画面。目标以外的线条始终写至50%，每个配对只改变目标末端。

- 完整参考、目标问题与预测掩码沿用上一轮；完整参考均显示所有线条。
- 0像素标签为完整，其余为部分。所有目标都已出现，均有完整参考。
- 输入为432×432，无裁剪、放大或彩色提示。线宽仍为3、5、7、9像素。
- 线条端点为整数轴向坐标。构造时确认每个缺口相对完整画面的变化像素数等于缺口长度乘线宽，避免遮挡使标签不可观察。
- `images.json`映射本轮当前图与复用参考；`queries.json`保留原目标查询编号；`cases.json`保存目标、缺口、标签及输入索引。
- 缺口、正确标签、线宽、变化像素数只用于构造与评分，不传给状态头。模型只接收UMM视觉特征、参考定位掩码与参考可用标记。

这些几何已经用于此前开发诊断。本轮冻结全部模型，固定六种条件后运行；不训练、不调阈值，不作为独立验收。原130例视觉留出测试继续保留。
