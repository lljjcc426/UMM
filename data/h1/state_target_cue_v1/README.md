# 目标位置提示的匹配训练对照

本数据用于比较UMM在相同训练预算下，是否能借助来自完整参考的目标位置提示，更准确地判断指定线条的存在与完成程度。两组均使用完整Show-o2视频理解UMM，当前任务仍为静态状态判断。

| 内容 | 无框组 `raw` | 蓝框组 `boxed` |
|---|---|---|
| 目标状态训练 | 原同图不同目标432题 | 同一432题，只增加目标框 |
| 缺少参考的复习 | 原视觉训练的312题，不画框 | 完全相同 |
| 文字复习 | 训练器混入原512道文字题 | 完全相同 |
| 参考＋当前问题 | 统一增加蓝框说明 | 相同说明、目标名称与问法 |
| 标签、样本顺序、初始化、训练预算 | 相同 | 相同 |

每组1256条训练输入，3轮、累积4，共942步。两组均从`h1_target_contrast_lora_v1`继续，最后8层q/v、rank 8、alpha 16、学习率2e-4、种子731；只评价最终权重。没有使用上一轮发生退化的集中训练权重。

蓝框使用完整参考中指定目标的边界外扩12像素，在参考区及当前区对应位置画3像素宽的蓝框。绘制只覆盖白色背景，保留所有原黑色笔迹。框的位置来自参考几何与目标名称，不读取当前进度；同一参考目标在缺失、部分和完整状态下使用相同边界。`box_sources.json`保存来源几何。**这些位置来自已知参考标注，属于辅助定位，不能计作自主定位。**

缺少参考时不加框，以免框的范围泄露原本没有提供的完整目标长度。两组的文字题和仅当前题保持相同，不因目标任务增加而移除这两项监督。训练只复用原train题；开发和视觉测试均不加入训练。

每组包含四份清单：

- `train`：432道目标状态题＋312道仅当前复习题。文字复习通过训练器另行加载。
- `train_reference`：432道已见目标状态题，用于检查训练内目标配对。
- `reference_dev`：原26个开发状态、104题，7个几何组。
- `all_targets_dev`：原12幅多线条开发画面的28个目标案例、112题，3个几何组。

每份清单分别保存输入和标签。无框图通过相对路径复用，蓝框图在各清单之间共享，共150张；原图像与原清单不改写。所有提示词与蓝框说明在两组间一致，因此主要输入变化为是否出现目标框。与此前没有该说明的原始评测相比，提示也发生变化，不能跨轮只归因于框。

运行前配置与结果入口见[实验记录](../../../results/h1/showo2_video_1_5b/target_cue_v1/README.md)。训练内和开发目标配对、文字及仅当前能力保持分别报告；开发同时交叉输入有框与无框图，不把有框成绩当作完整H1通过。

构建命令：`python scripts/h1_target_cue.py build`。构建器仅新增本目录、实验计划及派生清单，不修改原数据。原130例视觉测试继续留出。
