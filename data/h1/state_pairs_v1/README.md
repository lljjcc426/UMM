# 目标末端与背景的配对监督

**状态：仅数据构造和特征编码完成。2026-10-18按H1-v3任务转向时间事件，计划中的六次训练和评价均未执行。以下训练内容为原预注册计划，不代表结果。**

使用原训练集的48组几何、112个目标，不把开发几何加入训练。每个目标分配一个1、2、4、8或16像素末端缺口，分别构造完整／部分两种状态和两种背景，形成四个监督位置。

三组各有448个补充监督位置，目标、标签及顺序相同：

| 组别 | 四个位置的画面 |
|---|---|
| `replay` | 原有完整、最高部分进度，各重复两次 |
| `endpoint` | 其他线条写至50%，目标完整／指定缺口，各重复两次 |
| `paired` | 同样两种目标状态，分别配50%背景与变化背景 |

变化背景为其他每条线独立选择0%、25%、75%或100%。每个目标的缺口及背景在生成时固定，见`assignments.json`。重复位置保留，以匹配标签数、每批样本和更新预算；三组的不同画面数并不相等。

每步还混合16个原有状态案例。`train_replay.json`沿用上一轮进度覆盖的509例，包含未出现、部分、完整与无参考未知；`supplement_*.json`保存三组补充位置。训练实际批次的另外16例为四个目标各自的四个位置，不额外使用配对损失。

开发评价包含：

- `dev_previous.json`：旧317例，仅作能力保持。
- `dev_fresh.json`：上一轮441例，几何已经用于开发诊断。
- `dev_endpoint.json`：上一轮固定半条背景的336例，目标缺口0、1、2、4、8、16像素。
- `dev_background.json`：56个开发目标，缺口0、8、16像素，各配旧半条背景和新的15%／85%背景，共336例。其中168张变化背景图本轮新增，在训练前固定。

`images.json`前三段为已有进度覆盖图、已有末端配对图、新图；复用图用原路径引用。新图598张，其中430张用于训练、168张用于开发；18个全完整训练画面直接复用完整参考。所有输入均为432×432，无裁剪、放大或彩色提示。目标、标签和缺口等标注只用于监督与评分，不作为状态头输入。

这是开发实验，原130例视觉独立测试保留。新背景组合不能替代未见字形、字体或渲染来源的独立验收。见[脚本](../../../scripts/h1_state_pairs.py)与[完整实验记录](../../../results/h1/showo2_video_1_5b/state_pairs_v1/README.md)。
