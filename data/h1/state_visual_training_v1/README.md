# 当前线条状态：首轮视觉监督数据

用于H1的两项前置门槛，不包含顺序、方向或动作标签。由 `scripts/h1_state_gate.py build-visual-training` 生成，随机种子50623。

- 78个状态案例，21个几何组，156张432×432图像，624条JSON问答。
- 每个案例有“完整参考＋当前画面”和“只有当前画面”两个条件，各问存在、完成程度，每项两种问法。
- 覆盖单横、单竖、三条平行横线、两条平行竖线、交叉和折线；多线条中轮换指定目标，包含上/中/下横、左/右竖及交叉中的横/竖。
- 每组目标包括未出现、35%、75%和完整状态；其他线条随机处于未出现、半条或完整状态。
- 另有3组相同当前像素、不同参考长度的配对：短参考下完整，长参考下部分。移除参考后，已有线条的完成程度为未知。

本目录全部用于训练。开发评价沿用 `../state_gate_v1` 的26个dev案例；该目录的130个test案例继续留出。训练参考几何与线宽的组合没有与原dev/test重合。图形家族、布局、提示模板和Pillow渲染器相同，空白当前画面也可能重复；此划分不构成未见汉字、字体或渲染来源的泛化检验。

训练混入 `../state_training_v1` 的512条原文字训练问题，使用原文字开发集评价能力保持。不把已有文字测试集再次当作新的独立证据。标签单独保存在 `labels.jsonl`；模型输入仅为问题和图像，图像中没有数值长度或状态标签。

首轮设置在读取视觉训练后预测前固定：从文字状态LoRA继续，rank 8、alpha 16，语言模块最后8层q/v投影；冻结视觉编码与基础参数。624条视觉题与512条文字题共同训练2轮，梯度累积4，共568步，学习率2e-4。只评价最终检查点，不根据中途开发成绩选权重。训练和评价均使用同一原生图像编码与MMU提示组织。

`cases.json`保存几何和状态，`inputs.jsonl`保存问题与相对图像路径，`labels.jsonl`保存真值；这些展开行不能当作624个独立几何样本。
