# 参考位置监督与状态复习

定位训练使用36个新几何组、84个目标，包含三横、两竖、交叉各12组；目标位置、跨度与交叉位置随机变化，种子10418。图像为完整参考，上半部有线条，下半部空白。定位输入不含当前状态。训练与此前12组定位开发参考的完整几何签名不重复。

沿用此前诊断的同一问题和`{"box":[x_min,y_min,x_max,y_max]}`输出，监督中心路径边界。每个定位目标重复4次以增加任务权重，得到336条训练行；重复不增加独立目标数。再加入上一轮加框训练中的744条视觉状态题，通过训练器混入512条原文字题，共1592行。状态输入与答案保持原样，未将开发答案加入训练。

`cases.json`保存84个唯一定位目标，供训练内定位评价；`inputs.jsonl`、`labels.jsonl`为混合训练输入与监督。定位监督使用`response`字段保存完整JSON，旧状态监督仍使用`expected`字段。`plan.json`为运行前固定配置。

原28个定位开发目标已被检查过，只作为开发评价；原130例视觉留出测试继续保留。数据仍属于同一渲染方式和简单几何家族，不代表汉字、字体或时序泛化。

构建：`python scripts/h1_localization_training.py build`。运行：`python scripts/h1_localization_training.py run`。已有目录不可覆盖。见[运行设置与结果状态](../../../results/h1/showo2_video_1_5b/reference_localization_training_v1/README.md)。
