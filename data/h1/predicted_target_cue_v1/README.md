# 由模型预测目标位置的状态输入

复用已有12幅状态开发画面、28个目标案例和112道问题，包含3组几何、7个完整参考目标。状态标签、提示与旧有框／无框对照相同，只将位置提示替换为模型预测。

`references/`只保留完整参考的上半部，下半部涂白。完整UMM读取这张图及目标名称，新增目标空间头与已有全部笔迹头分别预测网格；两者取交集，以最大四连通部分给出框。目标头来自扩展几何训练，状态适配器没有再次更新。

预测框按已有规则外扩12像素，在参考与当前区域的对应位置画蓝框，只覆盖白色背景。模型定位不读取当前画面、完成比例或正确坐标。`localization_inputs.json`保存实际定位输入；`inputs.jsonl`保存状态输入；标签在定位与制图完成后才载入。坐标标注仅用于定位评分。

这是已被反复检查的开发集连接诊断，没有新留出状态或汉字泛化证据。完整设置与结果见[实验记录](../../../results/h1/showo2_video_1_5b/predicted_target_cue_v1/README.md)。

脚本入口为`python scripts/h1_predicted_target_cue.py build`、`locate`、`run-state`。原始数据与旧对照结果保持，新增参考图和预测框图不覆盖已有文件。
