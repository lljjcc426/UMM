# 固定笔迹的提示框扰动

复用已有3组开发几何、12幅状态画面、28个目标案例和112道问题。每个问题分别使用8种框变化，共896条输入、224张图片。同一黑色笔迹及状态标签保持，框的位置始终来自完整参考。

基准框为参考目标边界外扩12像素。八种变化分别是x方向平移±6像素、y方向平移±6像素、沿线方向两端各扩张／收缩6像素、垂线方向两侧各扩张／收缩6像素。这里的宽度是框在垂线方向的尺寸，蓝色边线本身始终为3像素。收缩后距中心路径仍有至少6像素余量。参考和当前区域应用相同变化，不根据当前完成程度调整。

蓝色只画在白色背景上；构建时逐图检查黑色笔迹像素完全保持，共224/224张。`cue_geometry.json`保存实际框边界；`inputs.jsonl`与`labels.jsonl`分别保存问题和评分标签。每个样本保留原问题及原案例编号，扰动变体共用原几何分组。

这是已查看开发集的配对干预，八个变体不能当作八倍独立几何。运行及评分见[实验记录](../../../results/h1/showo2_video_1_5b/cue_perturbation_v1/README.md)。脚本为`python scripts/h1_cue_perturbation.py build`；另一次构建需指定新的`--data`和`--output`仓库内路径。
