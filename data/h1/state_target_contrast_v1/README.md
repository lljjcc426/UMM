# 同图不同目标的状态监督

首轮视觉适配在训练内多线条子集上仍把6个缺失目标全部判为存在；开发集只保留正确目标后存在24/24，但完成仅19/24。后续优先加强“问题指定的目标对应哪条实际线”，并保留完成比较监督。蓝框未在小对照中改善表现，本数据不使用蓝框或外部实例隔离。

新数据的关键变化是：**同一张完整参考＋当前画面，分别询问每个目标；目标状态不同，正确答案也必须不同。** 单靠整张图是否有黑线或某个固定答案，无法同时答对这些问题。该设计提供明确的目标对应监督，实际收益仍由模型结果检验。

对每幅图、任务和问法，假设可以查看标签来选一个最有利的固定答案，但不随目标改变：新增参考视图的存在题最多172/216（79.6%），完成题最多144/216（66.7%）。该上限来自标签结构，实际模型成绩需单独测量；它说明忽略目标无法把新题全部拟合正确，不能单独证明模型学会了空间对应。统计保存在`build.json`。

- 种子70847，平行横线、平行竖线和交叉各2个新几何组，共6组。
- 三线布局采用未出现/部分/完整的循环组合及全部相同状态；两线布局覆盖三种状态的全部9种组合。部分进度为35%或75%。
- 48个实际画面，108个“画面＋指定目标”案例。每个案例包含两种视图、两类任务和两种问法，共864条新问题；同一画面的各目标复用完全相同的图像文件。
- 加入原视觉训练集全部624题作为复习，共1488条视觉题；另由训练器混入原512条文字训练题，总计2000条。
- 本目录全部属于train。新图像96张，原图通过相对路径复用；没有把已查看的开发或测试题加入训练。

在评价前固定：从首轮视觉适配权重继续，保持最后8层q/v、rank 8、alpha 16、学习率2e-4及答案交叉熵；训练1轮、累积4，共500步。原视觉编码和基础权重冻结，只评价最终检查点，不依据中途开发分数选权重。仍分别评价原视觉开发集的参考＋当前、仅当前，以及文字开发回归；原视觉测试保留。

这是一轮训练干预：改变了监督组合并增加训练步骤，没有等预算的原数据继续训练对照，不能把收益唯一归因于同图不同目标。蓝框和目标隔离控制也不计入主门槛。数据仍是固定渲染器的线条图形，不能作为未见汉字、字体或时间顺序的证据。

构建：`python scripts/h1_target_contrast.py`。`scenes.json`保存48幅新画面的真实线条状态；问题中不提供这些数值。`inputs.jsonl`和`labels.jsonl`分开保存，`source_dataset`区分新数据与复习数据。`build.json`记录固定训练设置。

本轮训练和开发评价已完成；最新完成两问均对仍17/26，同图不同状态的完成配对仍0/20，未显示稳定改善。详细分项与限制见[结果](../../../results/h1/showo2_video_1_5b/target_controls_v1/README.md)。
